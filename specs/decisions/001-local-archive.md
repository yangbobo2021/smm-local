# DR-001: 本地独立对话档案

## 状态

已接受。

## 背景

用户在不同项目中使用 Codex，未来也可能使用其他 Agent。
Agent 的源对话可能被删除，但已导入知识库的对话必须继续可用。

## 决策

第一版仅从本机 Codex 会话文件导入，以 SQLite 保存独立副本及全文索引。
导入器与统一记录格式分离，后续来源以新适配器接入。
以项目 ID 表达项目身份；路径是可修正的归属线索，不是项目身份。
项目关联为双向且仅展开一跳；同一项目的多个路径应映射到同一 ID。
Agent 检索默认排除当前会话，Web 手工检索默认不排除。
服务默认只监听本机回环地址。

## 影响

首版无需外部数据库或模型服务即可导入和检索。
源文件不存在后不会清除副本。
本机无法读取的云端 Codex 对话不在自动导入保证范围内。
