# DR-002: 双来源同事试用版

## 状态

已接受。

## 背景

首版只导入开发者本机 Codex 历史；其 Skill 虽可装入 Claude Code，但 Claude Code 历史尚不可检索。
安装说明依赖开发者个人目录，不能据此断言同事可以自行使用。

## 决策

沿用一份本地 SQLite 档案与原文检索接口，增加 Claude Code 本地文本会话适配器。
两种来源使用显式来源身份；导入时仅保留用户和助手可见文本，不把工具结果、思考或内部事件当作对话。
发行包提供可搬迁的本机安装、诊断和卸载流程；Skill 通过安装清单找到 CLI 路径。
用干净用户目录和两种 Agent 的新会话检验可用性，发行包不带任何人的历史对话。

## 影响

同事可只安装其中一种 Agent，仍能导入已有来源并检索。
实际同事价值需在本机验收后由同事亲自试用反馈；本机成功不等于普遍检索准确率。
