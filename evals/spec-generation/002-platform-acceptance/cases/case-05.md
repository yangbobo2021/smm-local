# SPEC 生成输入

## 生成指令

使用单独提供的 SPEC 模板，根据以下已确认意图和项目资料，起草供维护者审阅的规格。
直接输出规格正文，以材料为准，不执行测试或修改文件。缺少决定所需信息时在草稿中标明。

## 已确认意图

维护者希望 Hub 在机器重启后自动继续同步已配置的数据来源，保留现有归档和进度，
不要求重新输入凭据。来源不可达时保留可检索的归档并报告失败，恢复后重试且不重复导入。
