# SPEC 生成输入

## 生成指令

使用单独提供的 SPEC 模板，根据以下已确认意图和项目资料，起草供维护者审阅的规格。
直接输出规格正文，以材料为准，不执行测试或修改文件。缺少决定所需信息时在草稿中标明。

## 已确认意图

SMM 用户查看 `smm source --help` 时，不能从现有的“回退来源”说明判断它会影响适配器还是已导入对话。
本次只将 `rollback` 的简体中文用途改为“将该插件来源的适配器切回上一版，保留已导入对话”。
总帮助和 `smm source rollback --help` 都显示这一含义。命令名、参数、退出行为及真实回退操作均不变。

## 项目资料

- 本机端现有包支持 Windows、Linux、macOS，本次继续保留该范围。
- 当前电脑为 macOS。此次改动只修改同一 Python 模块里的静态 argparse 帮助字符串，
  三平台共用该定义，无平台分支。命令解析、终端编码、输出组件、依赖和打包配置均不改。
- 原版本在已支持平台均可显示中文帮助；没有针对本说明文本的渲染或编码缺陷报告。
- 两条帮助命令在创建档案对象前打印帮助，以状态码 0 退出，不访问来源、不写档案、不启动服务。
- 项目保留旧的回退功能测试。此变更的直接观察面是两条帮助输出、参数和退出行为。
