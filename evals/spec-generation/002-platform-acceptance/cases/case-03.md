# SPEC 生成输入

## 生成指令

使用单独提供的 SPEC 模板，根据以下已确认意图和项目资料，起草供维护者审阅的规格。
直接输出规格正文，以材料为准，不执行测试或修改文件。缺少决定所需信息时在草稿中标明。

## 已确认意图

SMM 返回两条同分检索结果时，顺序随输入列表顺序变化，不利于用户稳定定位同一会话。
本次让同分结果按数值会话 ID 升序排列。不同分数的原排序、结果字段、项目过滤及 limit 语义不变。

## 项目资料

- 现有客户端支持 Windows、Linux、macOS，三平台要求同样的稳定排序语义。
- 改动集中在一个三平台共用的纯函数：输入已解码的 Python 数值分数和整数会话 ID，输出排序后的列表。
  纯函数不访问系统、文件、数据库、网络、时间或区域设置，没有平台分支。
- 三平台使用相同受支持的 Python 数值比较语义，本次没有更改运行时范围、依赖、安装或服务。
- CLI、MCP 和 Web 均沿用这个函数的调用方式，没有各自的额外排序层或平台实现。
- 当前电脑为 macOS，可用合成输入验证同分、不同分、输入打乱和 limit 行为。
  没有其他系统的本次执行记录。
