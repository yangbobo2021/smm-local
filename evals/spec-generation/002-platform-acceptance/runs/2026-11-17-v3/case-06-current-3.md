# 规格：明确来源管理命令的帮助文案

本规格依据同目录下已确认的 [intent.md](intent.md)。无待维护者决定的事项。

## 预期行为

1. 用户执行 `smm source --help` 时，帮助以简体中文说明全部现有子命令的用途，用户无需进入各子命令帮助即可了解：

   | 子命令 | 帮助须表达的用途 |
   |---|---|
   | `list` | 查看本机来源状态。 |
   | `validate` | 使用来源清单和测试样本验收候选适配器。 |
   | `register` | 使用来源清单和测试样本验收候选适配器，验收通过后注册来源。 |
   | `enable` | 启用指定来源的导入。 |
   | `disable` | 停用指定来源的导入，保留已导入记录。 |
   | `rollback` | 将指定插件来源的适配器切回上一版。 |
   | `batches` | 查看指定插件来源的导入批次，返回记录中的 `id` 为批次 ID。 |
   | `purge-batch` | 按来源 ID 和整数批次 ID，从 SMM 本机档案删除该批次已导入的记录；清理前须先停用对应插件来源。 |

2. 用户执行 `smm source purge-batch --help` 时，帮助以简体中文说明：
   - `source_id` 是待清理批次所属的来源 ID。
   - `batch` 是整数批次 ID，可从 `smm source batches` 返回记录的 `id` 字段获取。
   - 操作会从 SMM 本机档案删除指定批次已导入的记录。
   - 清理前须先通过 `smm source disable` 停用对应插件来源；该来源仍启用时，清理会被拒绝。

3. 两条帮助命令均打印帮助，以状态码 `0` 退出，不写入档案。

## 边界与约束

- 变更仅限于 `smm source` 的 CLI 帮助文案，沿用简体中文用途说明。
- 保留全部现有命令名、参数名称、参数类型及必填要求：
  - `validate` 和 `register` 接收位置参数 `manifest` 及必填选项 `--fixture`。
  - `enable`、`disable`、`rollback`、`batches` 和 `purge-batch` 接收位置参数 `source_id`。
  - `purge-batch` 另接收整数位置参数 `batch`。
- 不改变子命令的执行行为、返回数据或清理前置条件。
- 文案须明确区分三种操作：`disable` 停止导入并保留记录，`rollback` 回退适配器版本，`purge-batch` 删除指定批次已导入的记录。
- 不要求逐字采用本规格表述，但不得省略或改变上述含义。

## 验收条件

1. `smm source --help` 列出全部八个现有子命令，每个子命令均有简体中文用途说明，且含义符合“预期行为”中的对应条目。
2. 顶层帮助能独立说明 `disable` 保留已导入记录、`rollback` 切回上一版适配器、`purge-batch` 删除本机档案中指定批次已导入的记录。
3. 顶层帮助明确提示：清理批次前须先停用对应插件来源。
4. `smm source purge-batch --help` 明确解释 `source_id` 和整数参数 `batch`，并说明批次 ID 来自 `smm source batches` 返回记录的 `id` 字段。
5. `purge-batch` 帮助明确说明删除范围、先执行 `smm source disable` 的前置要求，以及对应插件来源仍启用时会拒绝清理。
6. 两条帮助命令均正常打印帮助，以状态码 `0` 退出，且不写入档案。
7. 现有命令名、参数名称、参数类型、必填要求、执行行为及返回数据均保持兼容。
