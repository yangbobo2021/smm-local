# 规格：明确 source rollback 的简体中文用途说明

依据同目录下已确认的 [intent.md](intent.md)。现有材料足以确定本次变更范围，无待维护者决定事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 的用途说明显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 用户执行 `smm source rollback --help` 时，用途说明同样显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
3. 两条帮助命令均在创建档案对象前打印帮助，以状态码 `0` 退出，不访问来源、不写档案、不启动服务。

## 边界与约束

- 本次仅修改同一 Python 模块中的静态 argparse 简体中文帮助字符串，使说明明确区分适配器版本回退与已导入对话的保留。
- 命令名、参数、命令解析、退出行为和真实回退操作保持不变；其他帮助内容保持不变。
- 继续支持 Windows、Linux、macOS，三平台共用同一帮助定义，不增加平台分支。
- 不修改终端编码、输出组件、依赖或打包配置，不扩展为中文渲染或编码修复。
- 保留现有回退功能测试。本次直接观察范围为两条帮助输出及其参数和退出行为。

## 验收条件

1. `smm source --help` 的输出中，`rollback` 用途说明为“将该插件来源的适配器切回上一版，保留已导入对话”，不再使用原“回退来源”用途说明。
2. `smm source rollback --help` 的输出中，用途说明为相同文本。
3. 两条帮助命令均正常打印帮助并以状态码 `0` 退出，且不创建档案对象、不访问来源、不写档案、不启动服务。
4. 两条帮助输出中的命令名、参数定义及其他帮助内容与变更前一致。
5. 实际执行回退时，参数接受规则、退出行为和真实回退操作与变更前一致，现有回退功能测试予以保留。
6. 变更仅涉及三平台共用的静态帮助字符串；Windows、Linux、macOS 的支持范围不变，未引入平台分支或终端编码、输出组件、依赖、打包配置变更。
