# 规格：明确来源管理命令帮助

依据同目录下已确认的 [intent.md](intent.md) 及提供的项目资料。本次无待维护者确认事项。

## 预期行为

1. 用户执行 `smm source --help` 时，帮助以简体中文逐项说明全部现有子命令的用途：

   | 子命令 | 必须表达的用途 |
   |---|---|
   | `list` | 查看以来源 ID 为键的本机来源状态。 |
   | `validate` | 使用来源清单和测试样本验收候选适配器。 |
   | `register` | 使用来源清单和测试样本验收候选适配器，通过后注册来源。 |
   | `enable` | 启用指定来源的导入。 |
   | `disable` | 停用指定来源的导入，保留已导入记录。 |
   | `rollback` | 将指定插件来源的适配器切回上一版。 |
   | `batches` | 查看指定插件来源的导入批次。 |
   | `purge-batch` | 从 SMM 本机档案删除指定来源、指定批次已导入的记录；清理前必须先停用对应插件来源。 |

2. `smm source --help` 必须使用户能够区分：
   - 停用来源只停止该来源的导入，保留已导入记录。
   - 回退适配器将指定插件来源的适配器切回上一版。
   - 清理批次删除该批次已导入的记录，且对应插件来源仍启用时会拒绝清理。

3. 用户执行 `smm source purge-batch --help` 时，帮助说明清理对象、两个位置参数的含义及获取途径：
   - `source_id` 是要清理的插件来源 ID，可通过 `smm source list` 返回对象的键确认。
   - `batch` 是该来源下的整数批次 ID，可通过 `smm source batches <source_id>` 返回的批次记录中的 `id` 确认。
   - 清理前须执行 `smm source disable <source_id>` 停用同一插件来源；停用保留已导入记录，随后清理才删除指定批次的已导入记录。来源仍启用时，清理会被拒绝。

4. 两条帮助命令均打印帮助并以状态码 `0` 退出，在创建档案对象和执行子命令前结束，不写入档案。

## 边界与约束

- 变更仅涉及 `smm source` 的 CLI 帮助文案，沿用现有命令名、参数、必填性、参数类型及操作行为。
- `validate`、`register` 继续接收位置参数 `manifest` 和必填选项 `--fixture`；相关来源操作继续接收 `source_id`；`purge-batch` 继续接收整数位置参数 `batch`。
- 帮助不得将停用描述为删除记录，将回退描述为清理批次，或暗示可以清理仍启用的插件来源。
- 不新增交互、校验规则、档案变更或其他命令帮助的交付要求。
- 提供的项目资料未明确操作系统及部署支持矩阵。本次沿用既有支持范围，不据此新增或缩减平台承诺。变更为共用 CLI 帮助内容，不引入已知的平台专属行为。

## 设计决策

- 在父级帮助中为全部八个子命令提供用途摘要，并直接显示清理前停用来源的要求，使用户无需逐个打开子命令帮助即可选择操作。
- 在 `purge-batch` 帮助中提供参数含义、查询途径和停用前提，支持用户从该入口准备正确输入。
- 具体措辞可调整，但不得省略上述语义或改变现有操作承诺。
- 验收采用一个现有可运行 CLI 的环境中的真实帮助输出，结合共用帮助定义的审查。该覆盖适用于本次共用文案、参数展示和帮助退出路径；没有新增平台依赖或平台分支，因此无需所有平台重复完整验收，也不据此声称其他平台已实际运行通过。

## 验收条件

以下条件均须满足，方可判定本次交付通过：

1. 在现有可运行 CLI 的环境中执行 `smm source --help`，实际输出包含全部八个现有子命令，每条均有简体中文用途说明，语义符合“预期行为”中的对应条目。

2. 同一父级帮助输出明确表达以下完整区别：
   - `disable` 停止导入并保留已导入记录。
   - `rollback` 将指定插件来源的适配器切回上一版。
   - `purge-batch` 删除指定批次已导入的记录，且必须先停用对应插件来源；仍启用时拒绝清理。

3. 在同一运行环境中执行 `smm source purge-batch --help`，实际输出说明：
   - 清理范围为 SMM 本机档案中指定来源、指定批次的已导入记录。
   - `source_id` 的含义及通过 `smm source list` 的对象键确认它的途径。
   - `batch` 为整数批次 ID，以及通过 `smm source batches <source_id>` 的记录 `id` 确认它的途径。
   - 使用 `smm source disable <source_id>` 先停用对应插件来源，停用保留记录，清理删除指定批次记录；仍启用时拒绝清理。

4. 在上述运行环境中，两条帮助命令分别取得状态码 `0`，且均在创建档案对象和执行子命令前退出。验证不依赖预先创建档案；已有档案时也不发生写入。

5. 审查变更确认命令名、参数定义、必填性、整数类型及操作实现保持不变，变更仅限本次帮助文案。实际帮助输出与共用定义一致，不存在遗漏的平台专属帮助分支。

6. 交付记录包含上述实际运行环境及通过证据。共用内容审查不能替代两条帮助命令的实际运行证据；其他平台未运行的事实不得表述为已运行通过。
