# 规格：明确来源管理命令帮助

本规格依据同目录下已确认的 [intent.md](intent.md)。无待维护者决定的事项。

## 预期行为

用户执行 `smm source --help` 时，帮助以简体中文说明全部现有子命令的用途：

| 子命令 | 帮助须表达的含义 |
|---|---|
| `list` | 查看本机来源状态。 |
| `validate` | 使用来源清单和测试样本验收候选适配器。 |
| `register` | 使用来源清单和测试样本验收候选适配器，验收通过后注册来源。 |
| `enable` | 启用指定来源的导入。 |
| `disable` | 停用指定来源的导入，保留已导入记录。 |
| `rollback` | 将指定插件来源的适配器切回上一版。 |
| `batches` | 查看指定插件来源的导入批次列表，列表中每条记录的 `id` 为批次 ID。 |
| `purge-batch` | 从 SMM 本机档案删除指定插件来源、指定批次已导入的记录；清理前须先停用对应插件来源。 |

用户仅阅读 `smm source --help`，即可区分停用导入、回退适配器版本和删除批次已导入记录的作用，并知道可通过 `batches` 查询清理所需的批次 ID。

用户执行 `smm source purge-batch --help` 时，帮助须说明：

- `source_id` 指定待清理的插件来源。
- 整数参数 `batch` 指定导入批次 ID，可从 `smm source batches` 返回记录的 `id` 获取。
- 清理会从 SMM 本机档案删除该批次已导入的记录。
- 清理前须先通过 `smm source disable` 停用对应插件来源；该来源仍启用时，清理会被拒绝。

两条帮助命令均打印帮助并以状态码 `0` 退出，不创建档案对象、不执行来源操作、不写入档案。

## 边界与约束

变更仅涉及 `smm source` 的 CLI 帮助文案，沿用现有命令名、参数、参数类型、必填要求和操作行为。

- `validate`、`register` 继续接收位置参数 `manifest` 和必填选项 `--fixture`。
- `enable`、`disable`、`rollback`、`batches`、`purge-batch` 继续接收位置参数 `source_id`。
- `purge-batch` 继续接收整数位置参数 `batch`。
- `disable` 继续保留已导入记录；`rollback` 继续只将插件来源适配器切回上一版；`purge-batch` 继续在对应插件来源启用时拒绝清理。

帮助不得将停用或回退描述为删除已导入记录，也不得将清理描述为自动停用来源。具体措辞可调整，但须完整保留上述含义。

## 验收条件

1. 执行 `smm source --help`，全部八个现有子命令均显示简体中文用途说明，其含义与“预期行为”表逐项一致。
2. 来源总帮助明确说明 `validate` 负责验收，`register` 在验收通过后注册来源。
3. 来源总帮助分别明确说明：`disable` 停用导入且保留已导入记录；`rollback` 将插件来源适配器切回上一版；`purge-batch` 删除指定批次已导入的记录。
4. 来源总帮助说明 `batches` 用于查询指定插件来源的导入批次，并标明返回记录的 `id` 为批次 ID。
5. 来源总帮助明确提示，清理批次前须先停用对应插件来源。
6. 执行 `smm source purge-batch --help`，可独立读到清理范围、两个位置参数的含义、批次 ID 的获取方式，以及先停用对应插件来源的要求和来源启用时拒绝清理的行为。
7. 两条帮助命令均以状态码 `0` 退出，且不创建档案对象、不执行来源操作、不写入档案。
8. 所有现有命令名、位置参数、参数类型和必填选项保持不变；来源操作的现有行为保持不变。
