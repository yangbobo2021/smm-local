# 规格：明确 source rollback 简体中文帮助含义

依据同目录已确认的 [intent.md](intent.md)。本规格无待维护者决定事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 的简体中文用途显示为：“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 用户执行 `smm source rollback --help` 时，用途说明显示相同文案，使用户能够明确回退对象是该插件来源的适配器，已导入对话会保留。
3. 两条帮助命令均在创建档案对象前打印帮助，以状态码 `0` 退出，不访问来源、不写档案、不启动服务。查看帮助不新增输入、配置或运行前提。
4. 命令名、参数、解析规则、退出行为及真实回退操作保持不变。

## 边界与约束

- 本次仅修改同一 Python 模块中的静态 argparse 简体中文帮助字符串，不调整其他用途说明或功能。
- 本机端继续支持 Windows、Linux、macOS。
- 三平台共用该帮助定义且无平台分支；命令解析、终端编码、输出组件、依赖和打包配置均不变。
- 沿用现有中文帮助显示能力。本次没有需要修复的已知平台渲染或编码缺陷。
- 保留项目既有回退功能测试，不新增或改变真实回退行为。

## 设计决策

两处帮助入口使用完全一致的目标文案，分别明确“适配器切回上一版”和“保留已导入对话”，避免将“来源回退”误解为对已导入对话的操作。

本次验收可在当前 macOS 环境验证共用定义和两条实际帮助输出，无须在 Windows、Linux 重复完整测试。依据是：变更仅涉及无平台分支的静态字符串，三平台原有中文帮助能力已成立，且影响解析、编码、输出及打包的组件均未变化。该证据覆盖此次共用文案变更，不代表已在 Windows、Linux 实际运行通过。

## 验收条件

以下命令验收均在 macOS 上使用本次修改后的本机端执行，沿用原有正常运行条件，不新增来源配置或服务前提。

1. 执行 `smm source --help`，输出中的 `rollback` 用途为“将该插件来源的适配器切回上一版，保留已导入对话”，其他帮助内容保持不变。
2. 执行 `smm source rollback --help`，用途说明为同一目标文案，原有命令名、参数及其说明保持不变。
3. 对上述两条命令分别确认：帮助正常输出，退出状态码为 `0`；在创建档案对象前退出，未访问来源、未写档案、未启动服务。
4. 对照变更前后定义及输出，确认命令名、参数、解析规则和退出行为未改变；变更仅限目标帮助字符串，真实回退实现及既有回退功能测试保持不变。
5. 确认目标字符串仍由 Windows、Linux、macOS 共用的同一 Python 模块定义，未引入平台分支，也未修改编码、输出、依赖或打包配置。结合上述 macOS 实际输出证据，判定此次静态文案变更的覆盖充分；不要求新增 Windows、Linux 实际运行证据。
