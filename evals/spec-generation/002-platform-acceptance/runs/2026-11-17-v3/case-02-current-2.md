# 规格：明确 source rollback 的简体中文用途说明

本规格依据同目录下已确认的 [intent.md](intent.md)。现有材料足以确定本次变更，无待维护者决定事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 子命令的简体中文用途说明为：“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 用户执行 `smm source rollback --help` 时，用途说明同样为：“将该插件来源的适配器切回上一版，保留已导入对话”。
3. 两条帮助命令均保持现有帮助行为：在创建档案对象前打印帮助，以状态码 `0` 退出，不访问来源、不写档案、不启动服务。

## 边界与约束

- 本次仅修改同一 Python 模块中的静态 argparse 简体中文帮助字符串，使两个帮助入口均明确回退对象为该插件来源的适配器，并明确保留已导入对话。
- 命令名、参数、命令解析、退出行为及真实回退操作均保持不变；其他帮助内容保持不变。
- 继续支持 Windows、Linux、macOS。三平台共用同一帮助定义，不新增平台分支。
- 不修改终端编码、输出组件、依赖或打包配置，不扩展为中文渲染或编码修复。
- 保留项目已有的回退功能测试。

## 验收条件

1. `smm source --help` 输出中的 `rollback` 用途说明与指定文本“将该插件来源的适配器切回上一版，保留已导入对话”完全一致。
2. `smm source rollback --help` 输出中的用途说明与上述指定文本完全一致。
3. 两条帮助命令均以状态码 `0` 退出，且打印帮助前不创建档案对象，执行期间不访问来源、不写档案、不启动服务。
4. 除指定用途说明外，两个帮助入口展示的命令名、参数及其他帮助内容均与变更前一致。
5. 真实回退操作的行为与变更前一致，已有回退功能测试予以保留。
6. Windows、Linux、macOS 继续共用修改后的静态帮助定义，无新增平台分支；命令解析、终端编码、输出组件、依赖和打包配置均无变更。
