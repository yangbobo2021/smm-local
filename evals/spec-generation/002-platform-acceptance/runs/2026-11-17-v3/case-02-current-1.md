# 规格：澄清 source rollback 的简体中文用途说明

本规格依据同目录下已确认的 [intent.md](intent.md)。现有材料足以确定本次变更，无待维护者决定事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 子命令的用途说明显示为“将该插件来源的适配器切回上一版，保留已导入对话”，明确回退对象是该插件来源的适配器，并保留已导入对话。
2. 用户执行 `smm source rollback --help` 时，用途说明同样显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
3. 两条帮助命令均保持在创建档案对象前打印帮助，以状态码 0 退出，不访问来源、不写档案、不启动服务。

## 边界与约束

- 本次仅修改同一 Python 模块中的静态 argparse 简体中文用途字符串；除该说明文本外，其他帮助内容保持不变。
- 命令名、参数、命令解析、退出行为及真实回退操作均保持不变。
- 继续支持 Windows、Linux、macOS，三平台共用同一帮助定义，不引入平台分支。
- 不修改终端编码、输出组件、依赖或打包配置。
- 现有回退功能测试予以保留；本次不扩展回退功能，也不改变已导入对话的处理行为。

## 验收条件

1. `smm source --help` 输出中，`rollback` 的用途说明完整表达指定文本，不再使用原有“回退来源”作为其用途说明。
2. `smm source rollback --help` 输出中，用途说明完整表达相同的指定文本；终端自动换行不影响判定。
3. 两条帮助输出中的命令名、参数及其他帮助内容与变更前一致。
4. 两条帮助命令均以状态码 0 退出，且在创建档案对象前完成帮助输出，不访问来源、不写档案、不启动服务。
5. 变更仅涉及共用的静态帮助字符串，无平台分支或编码、输出组件、依赖、打包配置变更，Windows、Linux、macOS 的支持范围保持不变。
6. 真实回退操作及其参数、退出行为保持不变，现有回退功能测试保留。
