# 规格：明确来源管理命令帮助

依据同目录下已确认的 [intent.md](intent.md)。无待维护者决定的事项。

## 预期行为

1. 用户执行 `smm source --help` 时，帮助以简体中文说明全部现有子命令的用途，使用户能够区分以下操作：

   | 子命令 | 帮助须表达的用途 |
   |---|---|
   | `list` | 查看以来源 ID 为键的本机来源状态。 |
   | `validate` | 使用来源清单和测试样本验收候选适配器。 |
   | `register` | 使用来源清单和测试样本验收候选适配器，验收通过后注册来源。 |
   | `enable` | 启用指定来源的导入。 |
   | `disable` | 停用指定来源的导入，保留已导入记录。 |
   | `rollback` | 将指定插件来源的适配器切回上一版。 |
   | `batches` | 查看指定插件来源的导入批次；批次记录中的 `id` 是批次 ID。 |
   | `purge-batch` | 从 SMM 本机档案删除指定来源、指定批次已导入的记录；清理前须先停用对应插件来源。 |

2. 用户执行 `smm source purge-batch --help` 时，帮助须说明：
   - `source_id` 表示来源 ID。
   - `batch` 表示整数批次 ID，对应 `smm source batches` 返回的批次记录中的 `id`。
   - 清理会从 SMM 本机档案删除该批次已导入的记录。
   - 清理前须先通过 `smm source disable` 停用对应插件来源；来源仍启用时会拒绝清理。

3. 两条帮助命令均打印帮助并以状态码 `0` 退出，不创建档案对象、不执行来源操作、不写入档案。

## 边界与约束

- 本次仅调整 `smm source` 的 CLI 帮助文案，沿用简体中文用途说明。
- 保留全部现有命令名、参数名、参数类型和必填要求：
  - `validate`、`register` 接收位置参数 `manifest` 和必填选项 `--fixture`。
  - `enable`、`disable`、`rollback`、`batches`、`purge-batch` 接收位置参数 `source_id`。
  - `purge-batch` 额外接收整数位置参数 `batch`。
- 保持所有命令的现有操作行为，包括停用来源后保留已导入记录，以及对应插件来源仍启用时拒绝清理批次。
- 帮助须明确区分停用导入、回退适配器和删除批次记录的影响，不能将三者描述为同一种操作。
- 不要求逐字采用表中的措辞，但须完整、准确地表达其含义。

## 验收条件

1. `smm source --help` 列出全部八个现有子命令，每个子命令均有简体中文用途说明，含义符合“预期行为”中的对应条目。
2. 仅阅读 `smm source --help`，即可明确判断：
   - `disable` 停止来源导入并保留已导入记录。
   - `rollback` 将插件来源的适配器切回上一版。
   - `purge-batch` 删除 SMM 本机档案中指定批次已导入的记录。
3. `smm source --help` 明确提示清理批次前须先停用对应插件来源。
4. `smm source purge-batch --help` 明确说明两个位置参数的含义、`batch` 的整数类型及其与批次记录 `id` 的对应关系。
5. `smm source purge-batch --help` 明确说明清理影响，并提示先执行 `smm source disable`；对应插件来源仍启用时会拒绝清理。
6. 两条帮助命令均以状态码 `0` 退出，且在创建档案对象和执行子命令前完成退出，无档案写入。
7. 现有命令名、参数及必填要求保持不变；来源注册、启停、适配器回退和批次清理的实际行为保持不变。
