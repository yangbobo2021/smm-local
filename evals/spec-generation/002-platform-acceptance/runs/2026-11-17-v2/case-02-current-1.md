# 规格：明确 source rollback 的简体中文用途说明

本规格依据同目录下已确认的 [intent.md](intent.md)。现有材料足以确定本次变更，无待维护者决定的事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 子命令的简体中文用途说明显示为：“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 用户执行 `smm source rollback --help` 时，用途说明同样显示为：“将该插件来源的适配器切回上一版，保留已导入对话”。
3. 两条帮助命令均在创建档案对象前打印帮助，以状态码 `0` 退出；不访问来源、不写档案、不启动服务。

## 边界与约束

- 本次仅修改同一 Python 模块中的静态 argparse 帮助字符串，使两个帮助入口明确回退影响的是该插件来源的适配器，并保留已导入对话。
- 命令名、参数、命令解析、退出行为及真实回退操作均保持不变；其他帮助内容保持不变。
- 继续支持 Windows、Linux、macOS。三平台共用该帮助定义，不增加平台分支。
- 不修改终端编码、输出组件、依赖或打包配置。原版本已支持中文帮助显示，本次不扩展为编码或渲染修复。
- 保留项目现有的回退功能测试。

## 验收条件

1. 执行 `smm source --help`，`rollback` 对应的用途说明完整显示指定文案：“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 执行 `smm source rollback --help`，用途说明完整显示同一指定文案。
3. 两条帮助命令均以状态码 `0` 退出，且在打印帮助并退出前不创建档案对象、不访问来源、不写档案、不启动服务。
4. 两个帮助入口展示的命令名、参数及其他帮助内容与变更前一致。
5. 变更仅涉及共用模块中的静态帮助字符串；命令解析、退出行为、真实回退操作、平台支持范围、编码、输出组件、依赖和打包配置均未改变，现有回退功能测试予以保留。
