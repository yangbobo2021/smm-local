# 规格：明确来源管理命令帮助

依据同目录下已确认的 [intent.md](intent.md)。无待维护者决定的事项。

## 预期行为

用户执行 `smm source --help` 时，帮助以简体中文说明全部现有子命令的用途，使用户能够区分来源验收、注册、启停、适配器回退和批次清理：

| 子命令 | 帮助应表达的含义 |
|---|---|
| `list` | 查看以来源 ID 为键的本机来源状态。 |
| `validate` | 使用来源清单和测试样本验收候选适配器。 |
| `register` | 使用来源清单和测试样本验收候选适配器，通过后注册来源。 |
| `enable` | 启用指定来源的导入。 |
| `disable` | 停用指定来源的导入，保留已导入记录。 |
| `rollback` | 将指定插件来源的适配器切回上一版。 |
| `batches` | 查看指定插件来源的导入批次，返回记录中的 `id` 为批次 ID。 |
| `purge-batch` | 从 SMM 本机档案删除指定来源、指定批次已导入的记录；清理前须先停用对应插件来源，来源仍启用时会拒绝清理。 |

用户执行 `smm source purge-batch --help` 时，帮助应明确说明：

- `source_id` 是待清理批次所属的来源 ID。
- `batch` 是整数批次 ID，可从 `smm source batches` 返回记录的 `id` 获取。
- 清理会从 SMM 本机档案删除该批次已导入的记录。
- 清理前须先通过 `smm source disable` 停用对应插件来源；来源仍启用时会拒绝清理。

两条帮助命令均打印帮助并以状态码 `0` 退出，不要求提供子命令执行参数，不创建档案对象、不写入档案，也不执行来源管理操作。

## 边界与约束

本次变更仅限 `smm source` 的 CLI 帮助文案，沿用现有命令名、参数、参数类型、必填要求和操作行为：

- `validate`、`register` 保留位置参数 `manifest` 和必填选项 `--fixture`。
- `enable`、`disable`、`rollback`、`batches`、`purge-batch` 保留位置参数 `source_id`。
- `purge-batch` 保留整数位置参数 `batch`。

帮助不得将停用来源描述为删除已导入记录，不得将适配器回退描述为清理批次，也不得将清理批次描述为删除来源或源端数据。

帮助文案沿用简体中文；命令名和参数名保持原样。具体措辞可调整，但须完整表达上述含义。

## 验收条件

- 执行 `smm source --help`，可看到全部八个现有子命令及其简体中文用途说明，各项含义符合“预期行为”中的对应条目。
- 顶层帮助明确说明 `disable` 停用导入且保留已导入记录，`rollback` 将插件来源的适配器切回上一版，`purge-batch` 删除指定批次已导入的本机档案记录，三者影响可分别辨认。
- 顶层帮助明确提示清理批次前须先停用对应插件来源，并说明来源仍启用时会拒绝清理。
- 执行 `smm source purge-batch --help`，可看到 `source_id` 和整数参数 `batch` 的含义，以及通过 `batches` 返回记录的 `id` 获取批次 ID 的说明。
- `purge-batch` 帮助明确说明删除范围为指定批次已导入的 SMM 本机档案记录，并提示先使用 `smm source disable` 停用对应插件来源及启用状态下拒绝清理的行为。
- 两条帮助命令均无需补充执行参数即可打印帮助，以状态码 `0` 退出，且不创建档案对象、不写入档案、不执行来源管理操作。
- 现有命令名、参数、参数类型、必填要求及操作行为均保持不变；文案不存在“边界与约束”中列出的含义混淆。
