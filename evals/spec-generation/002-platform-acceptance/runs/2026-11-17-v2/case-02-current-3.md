# 规格：明确来源回退的简体中文帮助说明

意图依据：[intent.md](./intent.md)。本规格依据已确认意图起草，无待维护者决定事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 的简体中文用途显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 用户执行 `smm source rollback --help` 时，用途说明显示相同文本，明确回退对象为该插件来源的适配器，并保留已导入对话。
3. 两条帮助命令均在创建档案对象前打印帮助，以状态码 `0` 退出；不访问来源、不写档案、不启动服务。

## 边界与约束

- 本次仅修改同一 Python 模块中两条帮助入口所用的静态 argparse 简体中文用途说明。
- 命令名、参数、命令解析、退出行为及真实回退操作保持不变；其他帮助内容保持不变。
- 继续支持 Windows、Linux、macOS，三平台共用该帮助定义，不引入平台分支。
- 终端编码、输出组件、依赖及打包配置保持不变。现有资料未报告本说明文本的渲染或编码缺陷，本次不扩展为相关修复。
- 保留项目现有的回退功能测试。

## 验收条件

1. `smm source --help` 输出中，`rollback` 的用途说明为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. `smm source rollback --help` 输出中，用途说明为上述相同文本。
3. 两条帮助命令均以状态码 `0` 退出，且在退出前不创建档案对象、不访问来源、不写档案、不启动服务。
4. 除指定用途说明外，两条帮助输出的其他内容、命令名及参数保持不变。
5. 真实回退操作及其退出行为保持不变，现有回退功能测试得到保留。
6. Windows、Linux、macOS 继续共用修改后的静态帮助定义，未新增平台分支，也未修改终端编码、输出组件、依赖或打包配置。
