# 规格：明确来源回退的简体中文帮助说明

本规格依据同目录下已确认的 [intent.md](intent.md)。现有材料足以确定本次变更，无待维护者决定事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 子命令的简体中文用途显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 用户执行 `smm source rollback --help` 时，用途说明显示同一文案，明确回退对象是该插件来源的适配器，且保留已导入对话。
3. 两条帮助命令均在创建档案对象前打印帮助，以状态码 `0` 退出，不访问来源、不写档案、不启动服务。
4. `rollback` 的命令名、参数、退出行为及真实回退操作保持不变。

## 边界与约束

- 本次仅修改同一 Python 模块中的静态 argparse 简体中文帮助字符串，不扩展为回退功能变更。
- Windows、Linux、macOS 继续受支持，三平台共用同一帮助定义，不新增平台分支。
- 命令解析、终端编码、输出组件、依赖和打包配置均保持不变。
- 除上述用途文案外，现有帮助内容及命令行为保持兼容。
- 项目已有的回退功能测试予以保留；本次直接观察面为两条帮助输出、参数和退出行为。

## 验收条件

1. `smm source --help` 输出中，`rollback` 的用途文案为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. `smm source rollback --help` 输出中，用途说明为同一文案。
3. 两条帮助命令均以状态码 `0` 退出，且打印帮助前未创建档案对象，执行期间未访问来源、写入档案或启动服务。
4. 与变更前相比，命令名、可接受参数、参数解析结果及退出行为均未改变，其他帮助内容未改变。
5. 真实回退操作的行为未改变，已有回退功能测试未被删除或削弱。
6. Windows、Linux、macOS 仍共用同一静态帮助定义，无新增平台分支；命令解析、终端编码、输出组件、依赖及打包配置均未改变。
