# 规格：明确来源回退的简体中文帮助说明

依据：[已确认意图](intent.md)。

## 预期行为

1. 用户运行 `smm source --help` 时，`rollback` 的用途说明显示为“将该插件来源的适配器切回上一版，保留已导入对话”，明确回退对象是适配器，已导入对话会保留。
2. 用户运行 `smm source rollback --help` 时，用途说明显示同一句文本。
3. 两条帮助命令均以状态码 `0` 退出，在创建档案对象前打印帮助，不访问来源、不写档案、不启动服务。
4. 命令名、参数、命令解析、退出行为及真实回退操作保持不变。查看帮助无需新增输入、配置或来源访问前提。

## 边界与约束

- 本次仅修改同一 Python 模块中的静态 argparse 简体中文帮助字符串，不调整其他帮助内容或功能。
- 本机端继续支持 Windows、Linux、macOS，不缩减或扩大支持范围。
- 三平台共用该字符串定义，无平台分支。命令解析、终端编码、输出组件、依赖及打包配置均不变。
- 原版本在已支持平台均可显示中文帮助，且没有针对本说明文本的渲染或编码缺陷报告。
- 项目现有回退功能测试继续保留，不以此次文案修改改变其行为约定。

## 设计决策

此次变更的直接观察面是两条帮助输出及其参数和退出行为。由于只替换三平台共用的静态字符串，且不改变任何平台相关输出路径，当前 macOS 环境中的实际帮助输出验证，结合修改范围审查，足以验收本次改动；不要求 Windows、Linux 重复运行同一组帮助用例。

这一依据仅覆盖本次静态文案替换，不代表已在 Windows、Linux 实际运行验证。若修改涉及平台分支、编码、输出组件、依赖或打包配置，则超出本规格范围，需重新确认验收覆盖。

本草稿无待维护者决定的环境或接口事项。

## 验收条件

以下条件全部满足才算通过：

1. 在实际 macOS 环境中运行 `smm source --help`，`rollback` 对应的用途说明完整显示为“将该插件来源的适配器切回上一版，保留已导入对话”，中文可读，退出状态码为 `0`。
2. 在实际 macOS 环境中运行 `smm source rollback --help`，用途说明完整显示同一句文本，中文可读，退出状态码为 `0`。
3. 上述两条命令均无需新增配置或访问来源即可完成；帮助在创建档案对象前打印，执行期间不访问来源、不写档案、不启动服务。
4. 对上述两条实际帮助输出进行对照，除指定用途说明外，命令名、参数及其他帮助内容保持不变。
5. 修改范围审查确认：仅替换共用的静态 argparse 帮助字符串，没有新增平台分支，也未修改命令解析、真实回退逻辑、终端编码、输出组件、依赖或打包配置；现有回退功能测试保持保留。
6. Windows、Linux 的本次覆盖依据为共用定义及未变更的平台相关路径，不将其记为已取得实际运行证据。若第 5 条不成立，本次验收依据失效，不能按本规格判定交付通过。
