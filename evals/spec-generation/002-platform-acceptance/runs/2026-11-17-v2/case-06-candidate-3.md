# 规格：明确来源管理命令帮助

本规格依据同目录下已确认的 [intent.md](intent.md) 及提交 `5ce7e15204440ff605d0c7f40576fad9de9fd19e` 的项目资料。本次无待维护者确认事项。

## 预期行为

### 来源管理总帮助

用户执行 `smm source --help` 时，帮助以简体中文说明全部现有子命令的用途，使用户能据此选择操作：

| 子命令 | 帮助必须表达的含义 |
|---|---|
| `list` | 查看以来源 ID 为键的本机来源状态。 |
| `validate` | 使用来源清单和测试样本验收候选适配器。 |
| `register` | 使用来源清单和测试样本验收候选适配器，验收通过后注册来源。 |
| `enable` | 启用指定来源的导入。 |
| `disable` | 停用指定来源的导入，保留已导入记录。 |
| `rollback` | 将指定插件来源的适配器切回上一版。 |
| `batches` | 查看指定插件来源的导入批次。 |
| `purge-batch` | 从 SMM 本机档案删除指定来源、指定批次已导入的记录；清理前须先停用对应插件来源。 |

帮助必须清楚区分停用导入、回退适配器版本和删除批次记录。不得使用户误以为停用会删除记录，或回退适配器等同于清理已导入记录。

总帮助同时说明清理批次所需标识的获取途径：来源 ID 可从 `smm source list` 返回对象的键中确认；批次 ID 可通过 `smm source batches <source_id>` 查询，取批次记录的 `id`。

### 清理批次帮助

用户执行 `smm source purge-batch --help` 时，帮助以简体中文说明：

- `source_id` 是待清理批次所属插件来源的 ID，可从 `smm source list` 的结果中确认。
- `batch` 是该来源下的整数批次 ID，可通过 `smm source batches <source_id>` 查询，取目标批次记录的 `id`。
- 操作会从 SMM 本机档案删除该批次已导入的记录。
- 清理前须先执行 `smm source disable <source_id>` 停用对应插件来源；来源仍启用时会拒绝清理。停用本身保留已导入记录。

### 帮助执行行为

上述两条帮助命令均打印帮助并以状态码 `0` 退出，不要求用户提供子命令业务参数，不创建档案对象、不执行来源操作，也不写入档案。

## 边界与约束

本次仅修改 `smm source` 的 CLI 帮助文案，沿用现有简体中文风格。不得变更命令名、参数名、参数类型、必填要求、输出数据结构及操作行为。

现有参数约定保持不变：

- `validate` 和 `register` 接收位置参数 `manifest` 及必填选项 `--fixture`。
- `enable`、`disable`、`rollback`、`batches` 和 `purge-batch` 接收位置参数 `source_id`。
- `purge-batch` 另接收整数位置参数 `batch`。

不得将来源仍启用时拒绝清理的现有约束改成自动停用，也不得扩大删除范围。

项目资料未列明支持的操作系统或部署方式，本规格不新增、缩减或推断平台承诺。本次交付不涉及服务、适配器执行或平台相关运行逻辑。

## 设计决策

总帮助中的子命令用途说明须直接可见，不要求用户进入各子命令帮助才能理解停用、回退和清理的区别。清理前须停用的提示同时出现在总帮助和清理批次帮助中，覆盖用户从任一入口获取信息的情况。

本次变化是共用 CLI 定义中的静态帮助内容。验收须实际调用两条帮助命令，覆盖内容展示、参数解析及提前退出行为；在一个能够运行现有 CLI 的环境中取得这些证据即可支撑本次改动。由于未变更平台分支、文件访问实现、外部依赖或进程生命周期，无须各操作系统重复完整验收。该证据不代表其他平台已实际运行通过。

## 验收条件

以下条件均适用于同一个能够运行现有 CLI 的实际环境；交付记录须注明该环境及运行方式。

1. 执行 `smm source --help`，八个现有子命令均出现在帮助中，并分别表达“预期行为”表中的用途。仅阅读该输出即可区分：停用保留记录、回退切换适配器上一版、清理删除指定批次记录。

2. 同一总帮助明确提示清理批次前须停用对应插件来源，并说明来源 ID 来自 `list` 返回对象的键、批次 ID 来自 `batches` 返回记录的 `id`。

3. 不提供 `source_id` 和 `batch`，执行 `smm source purge-batch --help`，仍正常显示帮助。输出完整说明两个参数的含义、批次 ID 的整数要求、标识查询途径、删除范围、停用方式，以及来源仍启用时拒绝清理的约束。

4. 对上述两条帮助命令，在档案对象创建和来源操作均不应执行的状态下分别调用：两者均输出帮助、以状态码 `0` 退出，且未创建档案对象、未执行来源操作、未写入档案。两条命令均须独立取得通过证据。

5. 审阅变更后确认，仅帮助文案发生变化；现有命令及参数约定、业务输出和操作行为均保持不变。帮助中不存在自动停用、停用删除记录、回退清理记录或扩大批次删除范围的承诺。

全部条件通过后方可判定本次交付完成。具体机器、验证步骤、命令及证据保存方式写入 `plan.md`。
