# 规格：明确来源管理命令帮助

依据同目录下已确认的 [intent.md](intent.md) 及提供的项目资料编写。本次无待维护者确认事项。

## 预期行为

1. 用户执行 `smm source --help` 时，帮助以简体中文逐项说明全部现有子命令的用途，使用户能区分验收、注册、启停、回退和批次清理：

   | 子命令 | 帮助应表达的含义 |
   |---|---|
   | `list` | 查看以来源 ID 为键的本机来源状态。 |
   | `validate` | 使用来源清单和测试样本验收候选适配器。 |
   | `register` | 使用来源清单和测试样本验收候选适配器，通过后注册来源。 |
   | `enable` | 启用指定来源的导入。 |
   | `disable` | 停用指定来源的导入，保留已导入记录。 |
   | `rollback` | 将指定插件来源的适配器切回上一版。 |
   | `batches` | 查看指定插件来源的导入批次。 |
   | `purge-batch` | 从 SMM 本机档案删除指定批次已导入的记录；清理前须先停用对应的插件来源，来源仍启用时会拒绝清理。 |

2. `smm source --help` 应使用户明确理解三类操作的区别：`disable` 改变后续导入的启停状态并保留已有记录；`rollback` 切换适配器版本；`purge-batch` 删除本机档案中指定批次已导入的记录。

3. 用户执行 `smm source purge-batch --help` 时，帮助应说明清理效果、先停用对应插件来源的前提，以及两个位置参数的含义和获取途径：

   - `source_id`：待清理批次所属的插件来源 ID，可通过 `smm source list` 返回的状态对象键确认。
   - `batch`：该插件来源的整数批次 ID，可通过 `smm source batches <source_id>` 返回的批次记录中 `id` 字段确认。

   帮助应说明使用 `smm source disable <source_id>` 停用对应来源后再清理，且停用本身保留已导入记录。

4. 两条帮助命令均打印帮助并以状态码 `0` 退出，在创建档案对象和执行子命令前完成，不写入档案，也不执行来源管理操作。

## 边界与约束

- 本次仅修改 `smm source` 的 CLI 帮助文案，沿用现有命令名、参数名、参数类型、必填性和操作行为。
- `validate`、`register` 继续接收位置参数 `manifest` 和必填选项 `--fixture`；`enable`、`disable`、`rollback`、`batches`、`purge-batch` 继续接收 `source_id`；`purge-batch` 继续额外接收整数参数 `batch`。
- 清理范围是 SMM 本机档案中指定批次已导入的记录，文案不得将其描述为删除原始来源文件、删除整个来源或卸载插件。
- 不新增自动停用、自动回退、确认交互或其他操作行为。
- 提供的资料未列明 CLI 支持的操作系统或部署方式，本次不据此新增或缩减支持承诺。变更仅涉及共用帮助内容和既有参数解析路径，不引入平台专属行为。

## 设计决策

在来源命令总览中为每个子命令提供可直接理解的简体中文用途说明；在批次清理的详细帮助中说明参数获取方式及完整操作前提。清理前须停用来源的提示同时出现在两个帮助入口，分别满足命令发现和执行前查阅的需要。

本次交付可由当前执行环境中的共用帮助内容检查和实际 CLI 帮助调用验证支撑。理由是变更不涉及外部服务、账号、文件访问实现或进程生命周期调整，两个入口均在档案创建前退出。验证范围限于帮助内容、参数契约及退出路径，不据此宣称其他平台已经实际运行通过，也不要求各平台重复完整测试。

## 验收条件

以下条件均须通过；两个帮助入口共用当前执行环境的现有 CLI 运行方式验证，实际环境须随证据记录。

1. 执行 `smm source --help`，输出包含全部八个现有子命令及其简体中文用途说明，逐项符合“预期行为”中的含义；仅列命令名不算通过。

2. 检查总览输出，可分别确认以下结果：

   - `disable` 停用导入且保留已导入记录。
   - `rollback` 将插件来源适配器切回上一版。
   - `purge-batch` 删除本机档案中指定批次已导入的记录。
   - 清理前必须先停用对应插件来源，来源仍启用时拒绝清理。

3. 执行 `smm source purge-batch --help`，输出同时满足：

   - 说明批次清理的删除范围和先停用对应插件来源的前提。
   - 说明用 `smm source disable <source_id>` 停用来源，并说明停用保留已导入记录。
   - 将 `source_id` 解释为目标插件来源 ID，并指出可从 `smm source list` 的状态对象键确认。
   - 将 `batch` 解释为该来源的整数批次 ID，并指出可从 `smm source batches <source_id>` 返回记录的 `id` 字段确认。

4. 在档案尚未创建的状态下，分别调用两个帮助入口：均完整输出帮助、以状态码 `0` 退出，不创建档案对象、不创建或写入档案、不执行子命令。已有档案状态下，两条帮助命令也不得改变档案内容或来源状态；这些退出路径要求须有对应验证证据。

5. 对照既有 CLI 定义确认，全部命令名、位置参数、参数类型及必填选项保持不变；修改没有引入新的来源管理行为。文案不得承诺删除原始来源文件、删除整个来源或卸载插件。

6. 验收记录应明确区分共用内容与退出路径的验证结果和实际运行环境，不得把当前环境的通过结果表述为其他平台的实测结果。
