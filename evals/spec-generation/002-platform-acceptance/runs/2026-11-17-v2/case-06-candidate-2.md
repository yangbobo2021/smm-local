# 规格：明确来源管理命令帮助

本规格依据同目录下已确认的[意图](intent.md)及给定项目资料制定。无待维护者确认事项。

## 预期行为

1. 用户执行 `smm source --help` 时，帮助以简体中文说明全部现有子命令的用途，使用户能够区分以下操作：

   | 子命令 | 帮助须表达的含义 |
   |---|---|
   | `list` | 查看本机来源状态，结果以来源 ID 为键。 |
   | `validate` | 使用来源清单和测试样本验收候选适配器。 |
   | `register` | 使用来源清单和测试样本验收候选适配器，通过后注册来源。 |
   | `enable` | 启用指定来源的导入。 |
   | `disable` | 停用指定来源的导入，保留已导入记录。 |
   | `rollback` | 将指定插件来源的适配器切回上一版。 |
   | `batches` | 查看指定插件来源的导入批次，每条记录的 `id` 为批次 ID。 |
   | `purge-batch` | 从 SMM 本机档案删除指定来源、指定批次已导入的记录；清理前须先停用对应插件来源。 |

2. `smm source --help` 同时提供完成批次清理所需的操作指引：
   - 从 `smm source list` 返回对象的键取得来源 ID。
   - 使用 `smm source batches <source_id>` 查询该插件来源的批次，从批次记录的 `id` 取得批次 ID。
   - 先执行 `smm source disable <source_id>`，再执行 `smm source purge-batch <source_id> <batch>`；两处使用同一来源 ID。

3. 用户执行 `smm source purge-batch --help` 时，帮助说明：
   - `source_id` 是待清理批次所属的插件来源 ID，可通过 `smm source list` 查询。
   - `batch` 是整数批次 ID，取自 `smm source batches <source_id>` 返回的批次记录 `id`，须属于该来源。
   - 清理会从 SMM 本机档案删除该批次已导入的记录。
   - 清理前必须先用 `smm source disable <source_id>` 停用对应插件来源；来源仍启用时会拒绝清理。

4. 两条帮助命令均打印帮助并以状态码 `0` 退出，在创建档案对象和执行子命令前结束，不写入档案，也不执行来源管理操作。

## 边界与约束

- 本次仅修改 `smm source` 的 CLI 帮助文案，沿用现有命令名、参数、参数类型、必填性及操作行为。
- `validate`、`register` 继续接收位置参数 `manifest` 和必填选项 `--fixture`；本次不新增或改变其输入要求。
- `enable`、`disable`、`rollback`、`batches`、`purge-batch` 继续接收 `source_id`；`purge-batch` 继续接收整数位置参数 `batch`。
- 帮助必须明确区分停用导入、回退适配器和删除批次记录，不能暗示停用会删除记录，或回退会清理已导入记录。
- 项目资料未列出操作系统或部署方式的支持清单，本规格不据此新增或缩减支持承诺。本次文案与帮助解析路径没有已知的平台分支，不涉及平台专用功能或外部服务。

## 设计决策

- 在父级帮助中为八个子命令提供可直接理解的用途说明，并补充批次清理的输入来源和操作顺序；在 `purge-batch` 帮助中独立提供完整清理指引，使用户从任一指定入口都能理解清理前提。
- 不要求固定措辞、排版或换行，但必要含义必须出现在相应帮助输出中。
- 本次验收采用共用帮助内容和 CLI 解析路径的验证。改动不涉及操作系统接口、服务账号、文件访问机制或进程生命周期差异，因此无需各平台重复完整验收；该依据仅覆盖此次帮助文案改动，不代表其他平台已实际运行通过。

## 验收条件

以下条件共同适用于项目现有 CLI 的实际终端调用环境。帮助输出验证不以文案源文件检查或包构建代替。

1. 执行 `smm source --help`，输出包含全部八个现有子命令及对应的简体中文用途说明，含义符合“预期行为”中的表格。
2. 仅阅读父级帮助，即可明确判断：
   - `disable` 停用导入并保留已导入记录。
   - `rollback` 将插件来源的适配器切回上一版。
   - `purge-batch` 删除指定批次已导入的记录，且须先停用对应插件来源。
3. 父级帮助包含来源 ID、批次 ID 的查询途径，以及使用同一来源 ID 先停用、再清理指定批次的完整指引。
4. 执行 `smm source purge-batch --help`，输出保留 `source_id`、`batch` 两个位置参数，并明确其含义、查询途径、批次 ID 的整数要求及所属来源约束；同时说明删除范围、停用命令和来源启用时拒绝清理的前提。
5. 在无需提供子命令业务参数、无需预先准备来源或批次的状态下，两条帮助命令均成功打印帮助并以状态码 `0` 退出；未创建档案对象、未写入档案、未执行来源管理操作。
6. 命令定义核对确认所有现有命令名、参数、参数类型及必填性保持不变，变更仅涉及帮助文案。
7. 上述实际调用、内容检查及无副作用验证均取得通过证据后，本次交付才算通过。证据仅覆盖所用环境及上述共用逻辑，不宣称其他平台已经实际运行通过。
