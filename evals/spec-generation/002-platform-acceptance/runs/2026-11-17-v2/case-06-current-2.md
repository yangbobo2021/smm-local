# 规格：明确来源管理命令帮助

依据同目录下已确认的 [intent.md](intent.md)。无待维护者决定的事项。

## 预期行为

1. 用户执行 `smm source --help` 时，帮助以简体中文展示所有现有子命令的用途，使用户能够区分各命令的作用：

   | 子命令 | 帮助应传达的含义 |
   |---|---|
   | `list` | 查看以来源 ID 为键的本机来源状态。 |
   | `validate` | 使用来源清单和测试样本验收候选适配器。 |
   | `register` | 使用来源清单和测试样本验收候选适配器，验收通过后注册来源。 |
   | `enable` | 启用指定来源的导入。 |
   | `disable` | 停用指定来源的导入，保留已导入记录。 |
   | `rollback` | 将指定插件来源的适配器切回上一版。 |
   | `batches` | 查看指定插件来源的导入批次列表，其中每条记录的 `id` 为批次 ID。 |
   | `purge-batch` | 从 SMM 本机档案删除指定来源、指定导入批次已导入的记录；清理前须先停用对应的插件来源。 |

2. 用户执行 `smm source purge-batch --help` 时，帮助以简体中文说明：
   - `source_id` 是待清理批次所属的来源 ID。
   - `batch` 是整数批次 ID，对应 `smm source batches` 返回的批次记录中的 `id`。
   - 清理会从 SMM 本机档案删除该批次已导入的记录。
   - 清理前须先通过 `smm source disable` 停用对应的插件来源；来源仍启用时会拒绝清理。

3. 执行上述任一帮助命令时，打印帮助并以状态码 `0` 退出，不创建档案对象、不执行来源操作、不写入档案。

## 边界与约束

- 本次变更仅涉及 `smm source` 的 CLI 帮助文案，沿用现有命令名、参数、参数类型、必填要求和操作行为。
- `validate` 和 `register` 继续接收位置参数 `manifest` 及必填选项 `--fixture`。
- `enable`、`disable`、`rollback`、`batches` 和 `purge-batch` 继续接收位置参数 `source_id`；`purge-batch` 另接收整数位置参数 `batch`。
- 帮助必须明确区分停用导入、回退适配器版本和删除批次记录，不能将三者描述为同一种操作。
- 清理前停用来源是对现有前置条件的说明，不新增自动停用或其他操作。
- 不要求固定逐字措辞，但必须完整、准确地表达规定含义。

## 验收条件

1. `smm source --help` 列出全部八个现有子命令，每个子命令均有简体中文用途说明，含义与“预期行为”中的表格一致。
2. 仅阅读 `smm source --help`，即可确认：
   - `disable` 停止导入并保留已导入记录。
   - `rollback` 将插件来源的适配器切回上一版。
   - `purge-batch` 删除指定导入批次已导入的本机档案记录。
3. `smm source --help` 明确提示，清理批次前须先停用对应的插件来源。
4. `smm source purge-batch --help` 明确说明两个位置参数的含义、`batch` 的整数类型及其与批次记录 `id` 的对应关系，并说明删除范围。
5. `smm source purge-batch --help` 明确提示先执行 `smm source disable` 停用对应插件来源，并说明来源仍启用时会拒绝清理。
6. 两条帮助命令均打印帮助、以状态码 `0` 退出，且不创建档案对象、不执行来源操作、不写入档案。
7. 现有子命令、位置参数、参数类型及 `--fixture` 的必填要求保持不变；来源管理操作行为保持不变。
