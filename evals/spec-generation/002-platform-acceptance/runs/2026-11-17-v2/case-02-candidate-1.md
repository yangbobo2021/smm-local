# 规格：明确来源回退的简体中文帮助说明

依据同目录下已确认的 [intent.md](intent.md) 和项目现有承诺，本次仅修改 `rollback` 的简体中文用途说明，无待维护者决定的事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 的用途说明显示为“将该插件来源的适配器切回上一版，保留已导入对话”，明确回退对象是该插件来源的适配器，已导入对话会保留。
2. 用户执行 `smm source rollback --help` 时，显示相同的用途说明：“将该插件来源的适配器切回上一版，保留已导入对话”。
3. 两条帮助命令均在创建档案对象前输出帮助，以状态码 `0` 退出，不访问来源、不写档案、不启动服务。查看帮助无需配置来源或准备档案。
4. 命令名、参数及其含义、退出行为和真实回退操作保持不变。

## 边界与约束

- 本机端继续支持 Windows、Linux、macOS，不改变现有支持范围。
- 修改范围仅为同一 Python 模块中的静态 argparse 帮助字符串。三平台共用该定义，无平台分支。
- 命令解析、终端编码、输出组件、依赖和打包配置均保持不变。
- 不修改其他帮助内容，不改变适配器回退逻辑或已导入对话的处理方式。
- 保留现有回退功能测试。

## 设计决策

两条帮助入口采用完全一致的指定文案，避免用户对回退对象和对话保留行为产生不同理解。

本次验收以 macOS 上两条实际帮助输出及共用定义的审查为充分依据：变更仅涉及无平台分支的静态文本，三个支持平台原本均可显示中文帮助，且没有相关渲染或编码缺陷报告；本次也不改变影响平台差异的组件。因此，无需在 Windows、Linux 重复执行本次帮助验收。该依据仅覆盖此次文本变更，不代表已在这两个平台实际运行验证。

## 验收条件

1. **总帮助输出**：在 macOS 现有可运行的本机端环境中，无需配置来源或准备档案，执行 `smm source --help`，`rollback` 的用途说明为“将该插件来源的适配器切回上一版，保留已导入对话”，其他帮助内容和参数定义保持不变，退出状态码为 `0`。
2. **回退子命令帮助输出**：在相同环境和前提下，执行 `smm source rollback --help`，用途说明为同一指定文案，命令名、参数及其含义保持不变，退出状态码为 `0`。
3. **帮助无副作用**：上述两条命令均在创建档案对象前完成帮助输出并退出；不访问来源、不写档案、不启动服务。该条件分别适用于两个帮助入口。
4. **变更范围与兼容性**：审查确认变更仅涉及共用 Python 模块中的目标静态帮助字符串，无平台分支，未修改命令解析、终端编码、输出组件、依赖、打包配置或真实回退逻辑；Windows、Linux、macOS 的支持承诺保持不变。
5. **现有测试保留**：现有回退功能测试未被删除或削弱。本次不要求重复执行三平台真实回退测试，其依据是回退实现未变，直接观察面仅为两条帮助输出、参数和退出行为。
