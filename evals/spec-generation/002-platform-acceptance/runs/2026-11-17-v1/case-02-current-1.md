# 规格：明确 source rollback 的简体中文用途说明

依据同目录下已确认的 [intent.md](intent.md)。本草稿无待维护者决定事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 的简体中文用途说明显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 用户执行 `smm source rollback --help` 时，用途说明同样显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
3. 两条帮助命令均在创建档案对象前打印帮助，以状态码 `0` 退出，不访问来源、不写档案、不启动服务。
4. 命令名、参数、退出行为及真实回退操作保持不变。

## 边界与约束

- 本次仅修改同一 Python 模块中的静态 argparse 简体中文帮助字符串，不改变其他帮助内容或回退功能。
- 继续支持 Windows、Linux、macOS，三平台共用同一帮助定义，不新增平台分支。
- 命令解析、终端编码、输出组件、依赖和打包配置保持不变。
- 保留现有回退功能测试；本次直接观察面为两条帮助输出、参数和退出行为。

## 验收条件

1. `smm source --help` 输出中，`rollback` 的用途说明为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. `smm source rollback --help` 输出中，用途说明为“将该插件来源的适配器切回上一版，保留已导入对话”。
3. 两条帮助命令均以状态码 `0` 退出，且退出前不创建档案对象、不访问来源、不写档案、不启动服务。
4. 两条帮助输出中的命令名、参数及其他帮助内容与改动前一致。
5. 真实回退操作及其退出行为与改动前一致，现有回退功能测试得到保留。
6. Windows、Linux、macOS 继续使用同一静态帮助定义；无平台分支、编码、输出组件、依赖或打包配置变更。
