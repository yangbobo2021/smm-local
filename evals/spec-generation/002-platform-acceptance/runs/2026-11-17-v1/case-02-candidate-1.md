# 规格：明确来源回退命令的简体中文用途

依据同目录下已确认的 [intent.md](intent.md) 及项目现有承诺起草。本次无待维护者决定的事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 的简体中文用途显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 用户执行 `smm source rollback --help` 时，帮助正文显示同一用途说明。
3. 两条帮助命令均以状态码 0 退出，且在创建档案对象前输出帮助，不访问来源、不写档案、不启动服务。
4. 命令名、参数、解析规则、退出行为及真实回退操作保持原有行为。

## 边界与约束

- 本次仅修改同一 Python 模块中的静态 argparse 帮助字符串，不改变回退功能，也不增加对已导入对话的操作。
- 本机端包继续支持 Windows、Linux、macOS，不缩减或扩大支持范围。
- 三平台共用该帮助定义，且无平台分支。命令解析、终端编码、输出组件、依赖及打包配置均不变。
- 原版本已能在受支持平台显示中文帮助，且没有针对本说明文本的渲染或编码缺陷报告。本次不新增终端或编码支持承诺。

## 设计决策

两处帮助入口使用上述一致的用途说明，明确回退对象是该插件来源的适配器，并说明保留已导入对话。

本次验收以共享定义检查及 macOS 上两条实际帮助命令的输出为充分依据：变更仅涉及无平台分支的静态文本，既有中文输出能力及相关运行机制均不改变。因此无需在 Windows、Linux 上重复运行本次帮助文本验收，也不将 macOS 的结果表述为其他平台已实际运行通过。此覆盖结论仅适用于本次静态说明文本变更。

## 验收条件

1. 在 macOS 上执行 `smm source --help`，输出中 `rollback` 的用途为“将该插件来源的适配器切回上一版，保留已导入对话”，不再使用原有含糊说明。
2. 在 macOS 上执行 `smm source rollback --help`，帮助正文包含相同用途说明。允许 argparse 的正常换行，不改变文字内容和含义。
3. 两条帮助命令均以状态码 0 退出；确认帮助路径仍在创建档案对象前结束，不访问来源、不写档案、不启动服务。
4. 对照变更前后帮助输出及变更内容，确认命令名、参数和其余帮助内容保持不变，差异仅为指定用途说明及其自然排版变化。
5. 变更审阅确认只修改共享模块中的静态帮助字符串，未引入平台分支，未修改命令解析、退出逻辑、真实回退操作、终端编码、输出组件、依赖或打包配置；项目原有回退功能测试保持保留。
6. 完成上述共享定义检查及 macOS 实际运行验证后，可判定本次文本变更验收通过。该结论不代表重新验证了 Windows、Linux 的运行或打包能力。
