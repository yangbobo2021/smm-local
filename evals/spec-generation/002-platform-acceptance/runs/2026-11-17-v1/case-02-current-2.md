# 规格：明确来源适配器回退的中文帮助说明

本规格依据同目录下已确认的 [intent.md](intent.md)。现有材料足以确定本次变更，无待维护者决定事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 子命令的简体中文用途显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 用户执行 `smm source rollback --help` 时，用途说明同样显示上述文案，明确回退对象是该插件来源的适配器，且保留已导入对话。
3. 两条帮助命令均在创建档案对象前打印帮助，以状态码 `0` 退出，不访问来源、不写档案、不启动服务。

## 边界与约束

- 本次仅修改同一 Python 模块内的静态 argparse 帮助字符串，不改变命令名、参数、命令解析、退出行为或真实回退操作。
- Windows、Linux、macOS 继续受支持，三平台共用同一帮助定义，不新增平台分支。
- 不修改终端编码、输出组件、依赖或打包配置。现有资料未表明该说明存在中文渲染或编码缺陷。
- 除指定用途说明外，其他帮助内容保持不变；允许 argparse 按现有规则自动换行。
- 保留现有回退功能测试，不因本次文案变更调整回退功能的行为预期。

## 验收条件

1. `smm source --help` 的 `rollback` 用途说明包含完整指定文案；忽略自动换行后，文字为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. `smm source rollback --help` 的用途说明满足相同文案要求。
3. 两条帮助命令均以状态码 `0` 退出，且未创建档案对象、访问来源、写入档案或启动服务。
4. 命令名、接受的参数及其解析行为与变更前一致；其他帮助内容除自动排版外保持不变。
5. 真实回退操作保持原有行为，现有回退功能测试予以保留，其行为预期不变。
6. Windows、Linux、macOS 仍共用同一静态帮助定义，无新增平台分支，终端编码、输出组件、依赖和打包配置均未改变。
