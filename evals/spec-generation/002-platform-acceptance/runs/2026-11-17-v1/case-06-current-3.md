# 规格：明确来源管理命令帮助

本规格依据同目录下已确认的 [intent.md](intent.md)。无待维护者决定事项。

## 预期行为

用户执行 `smm source --help` 时，帮助使用简体中文说明全部现有子命令的用途，使用户能区分验收、注册、启停导入、回退适配器及清理批次：

| 子命令 | 帮助须表达的含义 |
|---|---|
| `list` | 查看以来源 ID 为键的本机来源状态。 |
| `validate` | 使用来源清单和测试样本验收候选适配器。 |
| `register` | 使用来源清单和测试样本验收候选适配器，通过后注册来源。 |
| `enable` | 启用指定来源的导入。 |
| `disable` | 停用指定来源的导入，保留已导入记录。 |
| `rollback` | 将指定插件来源的适配器切回上一版。 |
| `batches` | 查看指定插件来源的导入批次列表；记录中的 `id` 为批次 ID，可用于 `purge-batch`。 |
| `purge-batch` | 从 SMM 本机档案删除指定来源、指定批次已导入的记录；清理前须先停用对应插件来源，来源仍启用时拒绝清理。 |

用户执行 `smm source purge-batch --help` 时，帮助须说明：

- 该命令从 SMM 本机档案删除指定批次已导入的记录。
- `source_id` 是来源 ID；`batch` 是整数批次 ID，可通过 `smm source batches` 返回记录中的 `id` 获取。
- 清理前须先使用 `smm source disable` 停用对应插件来源；来源仍启用时拒绝清理。

两条帮助命令均打印帮助，以状态码 `0` 退出，不创建档案对象、不执行来源操作、不写入档案。

## 边界与约束

本次变更仅限 `smm source` 的 CLI 帮助文案，沿用现有命令名、参数、参数类型、必填性及操作行为。

- `validate` 和 `register` 继续接收位置参数 `manifest` 及必填选项 `--fixture`。
- `enable`、`disable`、`rollback`、`batches` 和 `purge-batch` 继续接收位置参数 `source_id`。
- `purge-batch` 继续接收整数位置参数 `batch`。
- 帮助须明确区分：`disable` 停止后续导入并保留已导入记录，`rollback` 切回上一版适配器，`purge-batch` 删除指定批次已导入的记录。
- 清理前停用来源是现有操作前提；本次仅在帮助中明确，不新增或改变校验规则。

## 验收条件

1. 执行 `smm source --help`，可见全部八个现有子命令，且每个子命令均有简体中文用途说明，含义符合“预期行为”表格。
2. 仅阅读 `smm source --help`，即可分别确认停用导入会保留已导入记录、回退会将插件适配器切回上一版、清理会删除指定批次已导入的记录。
3. `smm source --help` 明确提示清理批次前须先停用对应插件来源，并说明来源仍启用时拒绝清理。
4. 执行 `smm source purge-batch --help`，可见清理对象与删除范围、两个位置参数的含义、`batch` 的整数类型，以及从 `batches` 返回记录的 `id` 获取批次 ID 的说明。
5. `smm source purge-batch --help` 明确提示先使用 `smm source disable` 停用对应插件来源，并说明来源仍启用时拒绝清理。
6. 两条帮助命令均打印帮助并以状态码 `0` 退出；执行过程中不创建档案对象、不执行来源操作、不写入档案。
7. 所有现有命令名、参数名称、参数类型、必填性及操作行为保持兼容。
