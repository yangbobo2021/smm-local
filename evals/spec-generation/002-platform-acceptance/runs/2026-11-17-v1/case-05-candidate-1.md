# 规格：Hub 重启后自动恢复同步

意图依据：[已确认意图](intent.md)。本规格沿用 Python 3.11+ 的现有运行要求；操作系统、后台运行方式、部署账号及凭据持久化方案仍需维护者确认，不能据当前开发环境认定交付范围。

## 预期行为

1. 已配置数据来源并完成后台运行配置后，机器重启时 Hub 自动启动并继续同步，无需用户打开交互式终端、手动执行同步命令或重新输入凭据。
2. 自动恢复同步时，Hub 保留并使用已有归档和同步进度，不因重启清空归档、重置进度或重新导入已处理的数据。
3. 某个来源不可达时，Hub 保留该来源已有归档的检索能力，并报告同步失败。失败报告应能识别受影响的来源，且不得泄露凭据。
4. 来源恢复可达后，Hub 自动重试并继续同步，无需用户重新配置来源或凭据；重试不得重复导入已经归档的数据。
5. 现有前台同步命令继续可用，并保持通过环境变量提供凭据的现有行为。

## 边界与约束

- Python 3.11+ 是现有运行要求，不能据此推断操作系统或系统服务支持范围。README 示例路径和 macOS 开发电脑均不构成部署承诺。
- 本次新增的后台启动与凭据持久化涉及操作系统、服务环境、部署账号及文件访问权限。其支持范围尚未确定，必须在交付验收前由维护者明确；不得默认仅支持 macOS，也不得自行宣称支持 Windows 或 Linux。
- 当前仅有 macOS 交互式终端运行原前台命令的经历，不能证明新增后台运行、重启恢复或其他平台已经通过验证。
- 后台运行必须能够访问同一套已配置来源、归档及进度，不能因账号或工作目录变化而表现为首次运行。
- 凭据必须能够跨机器重启供后台进程使用，不得依赖原交互式终端继续存活或用户再次输入。
- 来源不可达不得导致既有归档丢失或不可检索。可检索性的验收入口及其运行依赖尚需确认。
- 同步中途发生重启属于恢复边界：不得跳过未完成的数据，也不得重复导入已经完成的数据。

## 设计决策

以下事项须由维护者确认并补入规格，不能仅交由实施计划决定：

| 待确认事项 | 对设计及验收的影响 |
| --- | --- |
| 本次承诺的操作系统及部署、运行方式 | 决定系统启动机制、进程生命周期及必须取得实际运行证据的环境 |
| 后台部署账号，以及是否要求用户登录前启动 | 决定凭据解锁、归档访问权限和重启验收状态 |
| 配置、归档、进度与凭据的持久化位置及访问权限 | 决定后台进程能否复用已有状态，以及凭据是否受到适当保护 |
| 凭据持久化机制、首次配置方式及与环境变量的优先关系 | 决定无需重输凭据能否成立，以及现有前台调用的兼容行为 |
| 失败报告与归档检索的用户入口 | 决定故障期间用户如何独立判断失败并检索已有内容 |
| 自动重试策略及恢复后允许的等待时间 | 决定重试行为及恢复时限的可判定标准 |

恢复设计必须保证归档写入、进度记录与去重判断相互一致。系统可能在同步任意阶段终止，因此验收必须覆盖中途重启，而不能只验证正常停止后的启动。

如后台与前台可能同时运行，须明确协调行为，保证不会因并发执行损坏进度或重复导入。

## 验收条件

1. **范围已确认**：维护者明确本次支持的操作系统、后台运行方式、部署账号及登录状态要求，并确认上述影响验收的待定事项。未确认时，不得判定交付通过。
2. **重启自动恢复**：在每个承诺的实际操作系统及后台部署环境中，完成配置后执行机器重启。Hub 在约定的登录状态下自动运行，使用原配置继续同步，全程无需打开终端、手动启动或重新输入凭据。
3. **状态保留**：上述重启后，原归档仍可检索，原同步进度得到延续；已导入数据不重复，未完成数据最终完成同步。
4. **中途重启恢复**：在同步尚未完成时发生机器重启，恢复后无数据遗漏、重复导入或状态损坏。涉及平台特定持久化或进程终止行为的环境必须取得实际通过证据。
5. **来源故障与恢复**：在实际后台运行环境中，使已配置来源不可达。Hub 保留既有归档的检索能力，并通过确认的入口报告对应来源失败；来源恢复后，在确认的重试时限内自动继续同步，且不重复导入。
6. **凭据与权限**：实际部署账号在重启后能够读取所需凭据及已有状态；凭据存储符合确认的访问权限要求，失败报告不泄露凭据。依赖用户登录解锁的方案必须按确认的登录状态验证。
7. **前台兼容**：原前台命令仍可通过环境变量取得凭据并完成同步；与持久化凭据同时存在时，行为符合确认的优先规则。
8. **并发安全**：若允许前台与后台同时启动，实际结果符合确认的协调规则，无重复导入或进度损坏。

共用逻辑测试可支撑重试、去重及进度处理的验证，但不能替代各承诺环境中的系统启动、账号权限、凭据可用性和重启恢复证据。共享逻辑无需在所有平台机械重复完整测试；平台特定机制及其与共享逻辑的集成必须实际验证。任何必需环境缺少通过证据，均属于未完成项。
