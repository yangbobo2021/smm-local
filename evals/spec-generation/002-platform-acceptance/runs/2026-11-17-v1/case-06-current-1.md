# 规格：明确来源管理命令帮助

本规格依据同目录下已确认的 [intent.md](intent.md)。无待维护者决定的事项。

## 预期行为

1. 用户执行 `smm source --help` 时，帮助使用简体中文说明全部现有子命令的用途：
   
   | 子命令 | 帮助应表达的含义 |
   |---|---|
   | `list` | 查看以来源 ID 为键的本机来源状态。 |
   | `validate` | 使用来源清单和测试样本验收候选适配器。 |
   | `register` | 使用来源清单和测试样本验收候选适配器，通过后注册来源。 |
   | `enable` | 启用指定来源的导入。 |
   | `disable` | 停用指定来源的导入，保留已导入记录。 |
   | `rollback` | 将指定插件来源的适配器切回上一版。 |
   | `batches` | 查看指定插件来源的导入批次，列表记录中的 `id` 为批次 ID。 |
   | `purge-batch` | 从 SMM 本机档案删除指定来源、指定批次已导入的记录；清理前须先停用对应插件来源。 |

2. 用户执行 `smm source purge-batch --help` 时，帮助明确说明：
   - `source_id` 是待清理批次所属的来源 ID。
   - `batch` 是整数批次 ID，可从 `smm source batches` 返回的批次记录 `id` 获取。
   - 清理会从 SMM 本机档案删除该批次已导入的记录。
   - 清理前须先使用 `smm source disable` 停用对应插件来源；来源仍启用时，清理会被拒绝。

3. 两条帮助命令均打印帮助，以状态码 `0` 退出，不创建档案对象、不执行子命令操作、不写入档案。

## 边界与约束

- 变更仅限 `smm source` 的 CLI 帮助文案，沿用现有命令名、参数、选项和操作行为。
- 帮助须清楚区分停用导入、回退适配器和删除批次记录，不能将三者描述为等价操作。
- `validate` 和 `register` 保持位置参数 `manifest` 及必填选项 `--fixture`。
- `enable`、`disable`、`rollback`、`batches` 和 `purge-batch` 保持位置参数 `source_id`；`purge-batch` 另保持整数位置参数 `batch`。
- 清理前停用的要求针对对应插件来源，不新增运行时检查或改变现有拒绝条件。
- 文案措辞和排版可调整，但不得遗漏上述含义或扩大命令实际能力。

## 验收条件

1. `smm source --help` 列出全部八个现有子命令，每条均有简体中文用途说明，含义符合“预期行为”中的对应条目。
2. 仅阅读 `smm source --help`，即可分别确认：`disable` 停止导入且保留已导入记录，`rollback` 将插件适配器切回上一版，`purge-batch` 删除本机档案中指定批次已导入的记录。
3. `smm source --help` 明确提示清理批次前须先停用对应插件来源。
4. `smm source purge-batch --help` 明确说明两个位置参数的含义、`batch` 的整数类型，以及通过 `batches` 返回记录的 `id` 获取批次 ID。
5. `smm source purge-batch --help` 明确说明删除范围、先执行 `smm source disable` 的要求，以及来源仍启用时会拒绝清理。
6. 两条帮助命令均以状态码 `0` 退出，且不创建档案对象、不执行子命令操作、不写入档案。
7. 现有命令名、参数、必填选项、参数类型及实际操作行为保持兼容。
