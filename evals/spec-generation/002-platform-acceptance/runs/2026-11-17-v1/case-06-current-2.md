# 规格：明确来源管理命令帮助

依据同目录下已确认的 [intent.md](intent.md)。无待维护者决定的事项。

## 预期行为

1. 用户执行 `smm source --help` 时，帮助以简体中文说明所有现有子命令的用途：
   - `list`：查看以来源 ID 为键的本机来源状态。
   - `validate`：使用来源清单和测试样本验收候选适配器。
   - `register`：使用来源清单和测试样本验收候选适配器，通过后注册来源。
   - `enable`：启用指定来源的导入。
   - `disable`：停用指定来源的导入，保留已导入记录。
   - `rollback`：将指定插件来源的适配器切回上一版。
   - `batches`：查看指定插件来源的导入批次列表，其中每条记录的 `id` 是批次 ID。
   - `purge-batch`：按来源 ID 和整数批次 ID，从 SMM 本机档案删除该批次已导入的记录；清理前须先停用对应的插件来源。

2. 用户执行 `smm source purge-batch --help` 时，帮助明确说明：
   - `source_id` 是待清理批次所属的插件来源 ID。
   - `batch` 是整数批次 ID，对应 `batches` 返回的批次记录中的 `id`。
   - 清理会从 SMM 本机档案删除该批次已导入的记录。
   - 清理前须先停用对应的插件来源，可使用 `smm source disable <source_id>`；来源仍启用时会拒绝清理。

3. 两条帮助命令均打印帮助并以状态码 `0` 退出，不创建档案对象、不执行来源操作、不写入档案。

## 边界与约束

- 变更仅限 `smm source` 的 CLI 帮助文案，沿用现有简体中文风格。
- 保留全部现有命令名、参数名、参数类型和必填要求：
  - `validate`、`register` 保留位置参数 `manifest` 和必填选项 `--fixture`。
  - `enable`、`disable`、`rollback`、`batches`、`purge-batch` 保留位置参数 `source_id`。
  - `purge-batch` 保留整数位置参数 `batch`。
- 保持现有操作行为，包括停用来源后保留已导入记录、回退到上一版适配器，以及拒绝清理仍启用的插件来源的批次。
- 帮助应清楚区分停用导入、回退适配器和删除批次记录，不暗示这些操作可以相互替代。
- 不要求逐字采用上述措辞，但必须完整保留其含义。

## 验收条件

1. `smm source --help` 列出全部八个现有子命令，且每个子命令都有与预期行为一致的简体中文用途说明。
2. 顶层帮助能够区分 `validate` 仅验收与 `register` 验收通过后注册的用途。
3. 顶层帮助明确说明 `disable` 停用导入并保留已导入记录、`rollback` 切回上一版适配器、`purge-batch` 删除指定批次已导入的记录。
4. 顶层帮助明确说明 `batches` 返回批次列表，记录中的 `id` 是批次 ID。
5. `smm source --help` 和 `smm source purge-batch --help` 均明确提示清理批次前须先停用对应的插件来源。
6. `purge-batch` 帮助明确说明两个位置参数的含义、`batch` 为整数且对应批次记录的 `id`、删除范围为 SMM 本机档案中的该批次已导入记录，以及来源仍启用时拒绝清理。
7. 现有命令、参数、必填要求及操作行为保持不变。
8. 两条帮助命令均以状态码 `0` 退出，且不创建档案对象、不执行来源操作、不写入档案。
