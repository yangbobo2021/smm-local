# 规格：澄清来源回退命令的简体中文用途

依据同目录下已确认的 [intent.md](intent.md)。当前材料足以确定本次变更范围，无待维护者决定事项。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 的简体中文用途显示为“将该插件来源的适配器切回上一版，保留已导入对话”，明确回退对象为该插件来源的适配器，已导入对话会保留。
2. 用户执行 `smm source rollback --help` 时，用途说明同样显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
3. 两条帮助命令均在创建档案对象前打印帮助，以状态码 `0` 退出，不访问来源、不写档案、不启动服务。

## 边界与约束

- 本次仅修改同一 Python 模块中的静态 argparse 简体中文用途字符串，不扩展为其他帮助文案调整。
- 命令名、参数、命令解析、退出行为及真实回退操作保持不变。
- 继续支持 Windows、Linux、macOS；三平台共用同一帮助定义，不新增平台分支。
- 终端编码、输出组件、依赖和打包配置保持不变。本次不包含中文渲染或编码修复。
- 保留现有回退功能测试，不因用途文案调整改变真实回退功能的行为约定。

## 验收条件

1. `smm source --help` 输出中，`rollback` 的用途文本为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. `smm source rollback --help` 输出中，用途文本为“将该插件来源的适配器切回上一版，保留已导入对话”。
3. 两条帮助命令均以状态码 `0` 退出，且在创建档案对象前完成帮助输出；执行期间不访问来源、不写档案、不启动服务。
4. 除指定用途文本外，帮助中展示的命令名、参数及其他帮助内容保持不变，参数解析与退出行为保持不变。
5. 真实回退操作保持原有行为，现有回退功能测试予以保留。
6. Windows、Linux、macOS 继续使用同一静态帮助定义，无新增平台分支；终端编码、输出组件、依赖和打包配置均无变更。
