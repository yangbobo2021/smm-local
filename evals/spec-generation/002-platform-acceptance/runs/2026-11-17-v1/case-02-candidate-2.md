# 规格：明确 source rollback 中文帮助含义

意图依据：[intent.md](intent.md)。本次仅澄清帮助文案，不改变回退功能。

## 预期行为

1. 用户执行 `smm source --help` 时，`rollback` 的简体中文用途显示为“将该插件来源的适配器切回上一版，保留已导入对话”。
2. 用户执行 `smm source rollback --help` 时，用途说明同样显示上述完整文案，明确回退对象是该插件来源的适配器，并保留已导入对话。
3. 两条帮助命令继续在创建档案对象前打印帮助，以状态码 `0` 退出，不访问来源、不写档案、不启动服务。
4. 命令名、参数、参数解析、退出行为及真实回退操作保持原有行为。

## 边界与约束

- 本机端继续支持 Windows、Linux、macOS，不调整支持范围。
- 变更仅涉及同一 Python 模块中的静态 argparse 帮助字符串，三平台共用该定义，无平台分支。
- 不修改命令解析、终端编码、输出组件、依赖及打包配置，也不扩展到其他帮助文案或功能。
- 帮助文案描述已有回退语义，不引入新的对话保留机制或改变现有数据处理行为。

## 设计决策

两处帮助输出采用相同的完整用途文案，避免用户从不同帮助入口获得不同含义。

本次验收可采用 macOS 上两条帮助命令的实际输出与行为证据，结合变更范围审查，支撑该静态文案变更在三平台共用定义中的一致性。依据是三平台使用同一无平台分支的定义、原版本均能显示中文，且本次不改变任何编码、输出或运行依赖。

无需为本次文案修改在 Windows、Linux 重复执行完整测试；上述依据不代表这两个平台已实际运行通过，也不覆盖未来输出组件、编码或打包方式发生变化的情况。现有材料没有需要维护者另行决定的交付范围事项。

## 验收条件

1. 在 macOS 实际执行 `smm source --help`，输出中 `rollback` 的用途完整显示为“将该插件来源的适配器切回上一版，保留已导入对话”，中文可读；允许 argparse 按终端宽度正常折行。
2. 在 macOS 实际执行 `smm source rollback --help`，用途说明完整显示相同文案，中文可读；允许正常折行。
3. 两条帮助命令均以状态码 `0` 退出，并确认帮助路径在创建档案对象前结束，不访问来源、不写档案、不启动服务。
4. 对照变更前后的命令定义和帮助输出，命令名、参数及其解析规则保持一致，除目标用途文案及其正常排版变化外，没有其他帮助内容变化。
5. 变更审查确认仅修改指定静态帮助字符串，未改变真实回退实现、终端编码、输出组件、依赖或打包配置；项目原有回退功能测试继续保留。
6. 以上必要证据齐备后，方可判定本次交付通过。跨平台适用结论限于本次共用静态文案变更，不表述为 Windows、Linux 已取得实际运行证据。
