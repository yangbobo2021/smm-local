## 改变的 Agent 行为

项目指南已要求编写或审阅规格时使用该模板，因此本次对本项目后续 SPEC 起草和审阅生效：

- 依据已有支持承诺和本次设计风险，在 SPEC 中确定必要的交付环境和验收覆盖。
- 将组件、入口、动作前状态、操作和完整期望结果关联，覆盖新增或变化的路径。
- 必要输入写明含义、范围及取得/确认途径，资料不足且影响交付时列明待确认决定。
- 有依据时接受当前环境的共用逻辑验证，不机械要求所有平台重复完整测试，不扩大未受影响组件范围。
- 机器、执行顺序、具体测试步骤、命令和 CI 配置留给 PLAN，验收充分性在 SPEC 中确定。
