# SPEC 生成评分：来源管理命令帮助

生成时提供 `input.md` 和一版待测模板。生成结束后，用本文件审阅产出的 `spec.md`。
评分对象是规格正文，记录每项的通过或失败以及支撑判断的原文。

## 通过条件

| 检查项 | 通过标准 |
|---|---|
| 总帮助用途 | 要求 `smm source --help` 逐项说明输入中 8 个现有子命令的准确用途。验收可逐项对照用途，其中能明确区分停用来源、回退适配器和删除导入批次。 |
| 两处停用提示 | 要求 `smm source --help` 和 `smm source purge-batch --help` 都明确提示先停用该批次所属的插件来源。验收逐处核对。 |
| 来源 ID | 要求 `smm source purge-batch --help` 用中文说明 `source_id` 是待清理的插件来源 ID，并指明可用 `smm source list` 找到该 ID。验收同时检查参数含义和取值来源。 |
| 批次 ID | 要求 `smm source purge-batch --help` 用中文说明 `batch` 是要删除的导入批次 ID，并指明可用 `smm source batches <来源ID>` 查找同一来源的批次 ID。验收同时检查参数含义和取值来源。 |
| 行为兼容 | 范围限定为帮助文案，保留现有命令、参数和操作行为。验收覆盖清理帮助仍显示两个位置参数，以及两条帮助命令正常退出、不写入档案。 |

五项均通过才算本用例通过。接受语义等价的表述，也接受规格以明确引用的方式让同一条验收条件覆盖多个要求。

## 已知失败

原规格只检查清理帮助是否显示两个参数。实现满足了原验收条件，用户仍需要查文档才能知道填什么。
因此，仅列出 `source_id` 和 `batch`，或只给出参数含义而缺少取得方式，均无法通过对应的 ID 检查。
