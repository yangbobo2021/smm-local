3. **已存在的文档错误：Skill 对 Hub 项目范围给出相互矛盾的指令。**

   `skills/smm-search/SKILL.md:39` 已要求使用 Hub 返回的实际项目范围；第 46 行却仍写着：

   > If `archive_scope` is `hub`, search covered all devices in the hub. Local project IDs do not filter the hub.

   当前 `src/smm_local/federation.py::search_archive()` 会将本机项目转换为稳定键并发送给 Hub；Hub 再按当前项目及直接关联筛选。因此，Agent 可能在实际只搜索 A、B、C 后，向用户报告覆盖整个 Hub，影响用户对漏检结果的判断。这与 `spec.md:24` 要求报告实际检索项目不符。

   应修改第 46 行，分别解释 Hub 全局检索和项目检索，并以返回的 `scope`、`effective_projects` 为依据。`TRIAL_GUIDE.md:38` 中“也可以在 Web『项目』中建立关联”也应注明仅适用于本机关系；Hub 关系应指向第 97–107 行的管理入口。
