# PR Review Prompt 对照执行结果

2026 年 11 月 17 日完成。候选版在 PR #21 的功能发现问题上表现更好，
但在仓库既有 CLI 帮助 EVAL 上回归。本轮结果不足以支持替换正式审查模板，
候选保留为实验稿。

| 评估项 | 当前 Prompt | 候选 Prompt |
| --- | --- | --- |
| Case 01，真实 PR 的入口缺口 | 0/3 次通过，逐次 2/5、2/5、1/5 | 3/3 次通过，均为 5/5 |
| Case 02，首页已介绍能力并直达指南 | 5/5，无入口缺失误报 | 5/5，无入口缺失误报 |
| Case 03，通过文档首页进入详细指南 | 5/5，无固定文件要求误报 | 5/5，无固定文件要求误报 |
| Case 04，既有 CLI 帮助 EVAL | 5/5，通过 | 2/5，未通过 |

评分要求每个样本的五项全部通过。Case 01 的检出差异在三次重复中一致，
但样本数量有限，不能据此推断其他 PR 的整体准确率。
Case 02、03 为人工构造对照。候选针对已知案例设计，本轮属于定向诊断。

本轮采用材料回放，输入含需求、计划、完整 diff、相关文档和历史验收记录。
Reviewer 没有重跑产品测试或访问真实服务器。所有结论均应按这个范围理解。

当前版三次均承认 README 的通用指南链接可继续，把第一次缺口定位在取得外部数据库连接资料。
它们没有指出 README 缺少新能力介绍，也没有提出明确的功能入口补充。
例如[当前版第一次回答](runs/2026-11-17/case-01-current-1.md)直接将
`README.md:33–50` 的多机说明及指南入口判为“此步可继续”。

候选版三次均指出，详细指南已存在，通用链接也可达，但首页缺少 VibeInsight 和 Hub 项目关联的能力提示。
它们将影响限定为发现难度，并建议简要介绍后链接已有章节。
[候选版第三次回答](runs/2026-11-17/case-01-candidate-3.md)明确写出
“新能力发现难度增加，操作未被阻断”，没有要求重复整套教程。

旧 EVAL 暴露了候选的另一种漏检。帮助实际只展示 `source_id batch`，
足以检查这个局部入口是否解释参数含义及取得方式。
[候选回答](runs/2026-11-17/case-04-candidate-1.md)却将来源和批次 ID 的取得均归为“材料不足”，
并得出“规格未覆盖、且已证实的用户路径缺口：无”。
[当前版回答](runs/2026-11-17/case-04-current-1.md)则识别了该帮助的具体信息缺口，
并区分了帮助缺口与整个 CLI 是否无法完成任务。
候选对完整主入口和替代路径证据的强调，使局部入口中已经可见的信息不足被弱化。

后续候选若继续调整，应保留对功能发现路径的核对，同时允许从材料已展示的局部入口审查具体信息缺口，
并准确限定结论适用范围。是否存在其他指南，与当前帮助是否给足必要引导，需要分别判断。
本轮执行后未调整候选或评分规则。

两版均使用 Codex CLI `0.166.0-alpha.5.1`，实际启动模型为 `gpt-6.1-sol`，
推理设置记录为 `none`。每次使用全新临时上下文、只读沙箱、独立会话，
不加载用户配置。两版的输入、共同输出要求和执行配置一致，仅替换待测 Prompt。
12 次审查全部成功返回，没有技术失败，也没有失败后重试。
旧 EVAL 的当前版先执行以检查运行链路，随后按交错顺序完成其他 11 次。
各次真实启动时间保存在执行回执中。

Prompt、输入、评分规则和运行器在首次执行前冻结哈希。
独立评分者只获得匿名回答、对应输入和规则，评分后恢复版本标签。
原始匿名评分和映射均保留。主审逐项核对判据与回答，并检查最终证据摘录逐字出自原回答。
部分评分摘录将不相邻文本拼接，最终评分表保留原始摘录，并另列已核对的连续原文。

有一项人工裁定。Case 02 当前版的 C5，匿名评分原为 0 分，最终改为 1 分。
原回答已经承认首页提供能力、角色和操作入口，后续的外部连接资料问题是单独提出的事项，
不能据此判定首页至指南的导航失败。该裁定按已冻结规则的导航范围执行，与 Case 03 采用相同边界。
详情见[逐项评分](runs/2026-11-17/scores.json)，原始评分文件完整保留。

输入与复跑方法见 [input.md](input.md)，判断标准见 [rubric.md](rubric.md)，
两版文本分别为[当前 Prompt](prompts/current.md)和[候选 Prompt](prompts/candidate.md)。
