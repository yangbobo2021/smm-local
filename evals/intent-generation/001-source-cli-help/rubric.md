# Intent 生成评分：看不懂来源管理子命令

生成阶段只提供 `input.md` 和待测的起草指引。生成完成后，
按下表逐项评分，并摘录草稿中的判断依据。

| 检查项 | 通过标准 |
|---|---|
| 还原已知问题 | 写清总帮助只列子命令名，终端用户难以判断该选哪个。 |
| 表达用户目标 | 将期望结果写成用户能从总帮助选对命令、分清关键操作的效果。 |
| 发现后续卡点 | 指出用户选中清理命令后，帮助只显示两个参数名，仍难以确定各填什么、到哪里取得参数值。 |
| 确认范围 | 提出一条具体问题，请维护者决定本次是做到从总帮助选对命令，还是还要让用户能根据清理命令的帮助准备正确的命令。两个选项的差异清楚，扩展范围标为待确认。 |

四项均通过才算用例通过。接受语义等价表述。
查到具体的 ID 查询命令可以作为发现卡点的依据。通过的关键是发现卡点并提出范围问题。
