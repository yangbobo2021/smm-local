## 当前工作历史问题的两组实测

从本机档案冻结 3617 段有内容的对话、17692 条消息，生成相同的隔离原始语料供两组使用；SMM 组指向该档案的独立快照。题目是继续 SMM 图谱设计时需要查的 `deployment.xml` 讨论：为何它不是产品或模块节点，产品属性如何保存，以及出处如何关联原文。题目、三条必需依据和语料清单在运行前冻结，分别以 SHA-256 `ec47d5749eab6a8de9a4cfedc61937aac88464018fe103bfea4a56a40119d3a5`、`30055747e6f6032307b6c0d124d4640548b2a526e78f184ea4a9bee6d5c49253` 标识。模型统一为 GPT-6 Luna／high，单次运行，无按答案重试。

运行器一度把正常模型输出文本中的 `429` 误判成服务限流。首次基线运行已成功且 `turn.completed`，因此在任何重试前中止；保留错误判定收据，修正仅依据失败事件判定限流，再继续尚未运行的 SMM 组。没有重复回答基线题，也没有按答案筛选结果。

## Claude Code 与待验收边界

隔离安装和本机 `claude mcp get smm-local` 均确认 MCP 已连接；本机默认模型配置为 DeepSeek。一次最小真实模型调用超过一分钟未返回，停止等待；另一次限定 45 秒的 `deepseek-chat` 调用同样超时，均未产出可评答案。因此 **Claude Code 真实新会话调用 SMM 并正确回答仍未验收**，问题发生在模型调用阶段，不能用 MCP 连接状态代替它。

此版可供已经能正常使用各自 Agent 的同事进行有限试用。正式交付仍缺同事独立安装、自然历史问题和跨 Agent 实际使用记录；目前没有获授权的其他同事历史档案。原始运行收据、题目及私人来源的完整副本保留在本机 `smm-local-private/rc2-live-001` 与 `rc2-claude-probe-001`，不公开。
