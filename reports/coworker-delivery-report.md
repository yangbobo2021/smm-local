### 技术检查

`pytest -q`：9 项通过。`spex lint`：无问题。本机 `smm doctor` 显示两个来源目录、两端 Skill/MCP、数据库和服务均正常；它明确输出 `model_auth_checked=false`，因此不会把接入检查误当成模型登录验收。对本机约 3500 段对话的四个代表查询做 5 次计时，Top5 检索中位数约 0.6–94 毫秒；这些只说明本机词法索引速度，不代表任意问题的召回率。

发行包独立安装经历两次原样保留的失败：第一次在线下载 Python 依赖超过 15 分钟而被验收进程终止；第二次在空白 HOME 中使用本机已缓存的 wheel 完成安装，但验收脚本把 macOS `/var` 与 `/private/var` 视为不同路径，导致误判。修正路径规范化后，第三次在同样的空白 HOME 和预热 wheel 条件下，干净安装、重复安装、搬迁、两端 MCP 与保留数据库卸载六项均通过。由此可证明安装逻辑可用，不能证明任意同事网络下的首次下载耗时。试用指南给出了公司 Python 镜像配置入口。

## 仍需同事验证

至少两位非开发者按指南独立安装；每人用一题真实历史问题和一题跨 Agent 问题，看是否主动调用 SMM、是否读到支持答案的原文、是否有使用价值。记录失败案例与耗时。A07 的模型鉴权问题要在一台能正常使用 Claude Code 的机器上重跑，才可把双 Agent 实答验收标为通过。
