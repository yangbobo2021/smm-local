项目文档
检索明确采集的本机与 Hub 文档。文档与对话共用项目及双向直接一层关联；项目文档同步默认关闭，独立于对话选择。支持严格 UTF-8 的 .md、.markdown、.txt；Word、Excel、PDF、图片尚不支持。
只有明确“刷新”读取外部来源；网页上传/更新明确保存并采集 SMM 副本。保存路径配置、搜索、读取及重启不会刷新；源文件不改写。内容只去 BOM 并把 CRLF/CR 转 LF，其他字符保留。每文件 2MiB，每来源 1000 候选及 16MiB。个别文件错误为 partial，来源枚举/预算错误为 failed。

    
创建普通本机项目
项目可同名，以 #ID 区分。需要全局项目时，在“项目”页创建；全局与普通项目同级，不自动加入其他项目。

    
上传到本机项目文档库
本机创建的项目只在本机管理；Hub 上的副本只读。上传保存到 SMM 专用副本库，不改你的原文件。
    将文档拖到这里上传到所选本机项目；或使用上面的文件选择器。
    
    
    项目文档同步选择
    允许后同步该项目已采集及未来明确纳入的文档。暂停保留 Hub 快照；发现删除/失效仍撤回。共享文件经其他获准项目更新时，暂停项目的连续资格仍可能读到新文件版本。
    
    
    添加文档来源
    可多选；不选仅参加全部文档查询。ID 也可在“项目”页取得。
    * 匹配单段，? 匹配单字符，** 匹配零或多层目录，尾 / 排除目录；禁止绝对路径、.. 和反斜杠。默认跳过隐藏、版本库与构建目录；不跟随符号链接/junction。可另行明确添加其中的实际文件或子目录。
    修改来源会完整替换项目、排除与递归配置，使其旧材料立即退出检索/读取并回到 pending；根路径不能更改。按新配置刷新后生效。
    
    
    来源与覆盖
    
    
    检索采集文档
    Hub创建的项目文档只在创建端管理。打开Hub管理文档；请向Hub维护者取得当前凭据文件，打开后在Hub页面明确选择。本机不会通过链接传递凭据。
    
    
    文档原文 · 采集版本
    范围针对整个采集文本，Unicode 码点从 0 开始，左含右不含；不是字节或 UTF-16，一次最多 16000 字符。内容/配置/连续资格失效后旧引用拒绝，须重新搜索；首版不读历史版本。其他重叠有效来源可保留当前文件级快照，移除最后来源退出检索/读取。
    
  
    
  
    
    
    对话上传
    项目选择（仅指定 / 排除指定）
    仅指定的空名单不上传；排除指定的空名单全部上传。新项目按所选规则处理。首版上传仅支持 Codex、Claude Code，其他已归档来源仍参与本机检索。
    规则差异
    保存与 Hub 确认分别显示。停止仅影响后续上传，旧副本继续可检索和读原文；重新允许会补齐全部未确认历史。
    
    
    同步配置
    服务仅监听本机地址；导入后的知识库数据不会因源对话删除而自动删除。
