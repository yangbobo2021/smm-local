# 规格：完善来源管理和批次清理帮助

依据 [已确认的意图](intent.md)。

## 预期行为

### 总帮助

运行 `smm source --help` 时，帮助页为现有 8 个子命令各提供一句简体中文用途说明。
说明应表达下表中的含义，措辞可等义调整。

| 子命令 | 用途说明应表达的含义 |
|---|---|
| `list` | 列出本机对话来源及其状态。 |
| `validate` | 验收候选来源适配器。 |
| `register` | 验收并注册来源适配器。 |
| `enable` | 启用指定来源的导入。 |
| `disable` | 停用指定来源的导入，保留已导入的记录。 |
| `rollback` | 将指定插件来源的适配器切回上一版。 |
| `batches` | 查看指定插件来源的导入批次。 |
| `purge-batch` | 从 SMM 本机档案删除指定批次已导入的记录。 |

`purge-batch` 的条目还应提示，清理批次前须先停用该批次所属的插件来源。

### 清理批次帮助

运行 `smm source purge-batch --help` 时，帮助应以简体中文说明清理会删除该批次已导入
SMM 本机档案的记录，并提示用户先用 `smm source disable <来源ID>` 停用同一插件来源。

帮助应在两个位置参数旁分别用简体中文说明含义和查法。

| 参数 | 含义与查法 |
|---|---|
| `source_id` | 待清理批次所属的插件来源 ID，从 `smm source list` 的结果中查找对应来源。 |
| `batch` | 要删除的导入批次 ID，用 `smm source batches <来源ID>` 查询同一来源，取目标批次记录的 `id`。 |

## 边界与约束

改动范围限于 `smm source` 的总帮助和 `purge-batch` 的子命令帮助。沿用现有子命令名、
参数和操作行为。两条帮助命令均只显示帮助并以状态码 `0` 退出，不创建或写入档案。

## 验收条件

1. `smm source --help` 列出全部 8 个现有子命令。逐项核对，每条简体中文说明均准确表达表中的用途。
2. 总帮助的 `purge-batch` 条目和子命令帮助都提示清理批次前须先停用该批次所属的插件来源。
   子命令帮助还说明删除范围，并显示 `smm source disable <来源ID>` 的用法。
3. `smm source purge-batch --help` 在 `source_id` 参数旁用简体中文说明这是待清理批次所属的
   插件来源 ID，并指明用 `smm source list` 查找。
4. `smm source purge-batch --help` 在 `batch` 参数旁用简体中文说明这是要删除的导入批次 ID，
   并指明用 `smm source batches <来源ID>` 查询同一来源，取目标批次记录的 `id`。
5. 清理批次帮助仍显示 `source_id` 和 `batch` 两个位置参数。两条帮助命令均以状态码 `0` 退出，
   查看帮助前后档案保持原样，未创建的档案也不会因查看帮助而创建。
