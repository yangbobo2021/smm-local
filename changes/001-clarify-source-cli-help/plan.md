# 计划：完善来源管理和批次清理帮助

依据[已确认的规格](spec.md)。本计划合并到 `main` 后，继续更新仍开放的实现 PR。
[PR #7](https://github.com/yangbobo2021/smm-local/pull/7)

## 修改位置

- `src/smm_local/cli.py` 中的 `smm source` 参数解析定义。沿用 PR #7 中 8 个子命令的中文用途说明和两处停用提示，补全清理批次的子命令帮助。
- PR #7 中的 `tests/test_cli_help.py`。扩展两条帮助命令的回归测试，验证参数说明的位置、内容和档案状态。使用现有的 `tests/test_source_plugins.py` 回归验证实际操作行为。

## 实施顺序

1. 扩展帮助测试，分别检查 `source_id` 和 `batch` 各自旁边的中文说明与查找命令，并检查子命令帮助给出的停用命令。
2. 在 `purge-batch` 的子命令说明中写明删除范围，并给出 `smm source disable <来源ID>`。保留总帮助中清理前须停用对应插件来源的提示。
3. 给两个位置参数分别添加简体中文帮助。`source_id` 说明如何用 `smm source list` 找到插件来源 ID。`batch` 说明如何用 `smm source batches <来源ID>` 查询同一来源，并取目标批次记录的 `id`。保留现有命令名、参数顺序和类型、实际操作行为。
4. 用实现分支的 CLI 和临时档案逐项验收，运行回归测试，并把实际输出附到实现 PR。

## 验证方法与通过条件

| 规格验收项 | 验证方法 | 通过条件 |
|---|---|---|
| 1. 总帮助的 8 条用途说明 | 运行 `smm source --help`，逐条对照规格表 | 全部 8 个子命令都有准确的简体中文说明，能分清停用来源、回退适配器和清理批次的效果 |
| 2. 两处停用提示及删除范围 | 对照总帮助中的 `purge-batch` 条目和 `smm source purge-batch --help` | 两处都提示先停用批次所属的插件来源。子命令帮助还说明会删除该批次已导入 SMM 本机档案的记录，并给出 `smm source disable <来源ID>` |
| 3. `source_id` 的含义与查法 | 查看子命令帮助中 `source_id` 对应的条目 | 条目用简体中文说明这是待清理批次所属的插件来源 ID，并指向 `smm source list` |
| 4. `batch` 的含义与查法 | 查看子命令帮助中 `batch` 对应的条目 | 条目用简体中文说明这是要删除的导入批次 ID，并给出 `smm source batches <来源ID>`，明确查询同一来源并取目标批次记录的 `id` |
| 5. 参数兼容性与档案状态 | 测试两条帮助命令，每条分别使用不存在的数据库路径和已初始化的临时档案 | 子命令仍显示 `source_id`、`batch` 两个位置参数。两条命令都以状态码 `0` 退出，未创建的档案仍不存在，已有档案的文件内容及伴随文件保持原样 |

运行 `pytest -q tests/test_cli_help.py tests/test_source_plugins.py`。实现 PR 附上两条帮助命令的完整输出及退出码、临时档案检查结果和 `pytest` 摘要。按规格第 1–5 项逐项标记通过、失败或未验证，并指向对应证据。
