# 意图：让用户选对来源管理命令，并知道如何准备批次清理

## 现有问题

试点开始时，`smm source --help` 只列出子命令名。用户难以判断该用哪条命令，
尤其难以分清停用来源、回退适配器和删除导入批次的效果。

用户选中清理命令后，`smm source purge-batch --help` 中的参数只有名称。
用户还得查文档，才能知道 `source_id` 和 `batch` 分别填什么、从哪里取得。

## 受影响的用户

通过终端接入或维护本机对话来源的 SMM 用户，尤其是首次查找来源管理命令
或需要清理某次导入记录的用户。

## 期望结果

用户查看 `smm source --help` 后，能了解现有 8 个子命令的用途，选出适合当前任务的命令，
并分清停用来源、回退适配器和删除导入批次各自会改变什么。

需要清理批次时，用户查看 `smm source purge-batch --help` 就能知道：

- `source_id` 是要清理的插件来源 ID，可从 `smm source list` 的结果中找到。
- `batch` 是要删除的导入批次 ID。用 `smm source batches <来源ID>` 查询同一来源，
  取目标批次记录中的 `id`。
- 清理会删除该批次已导入 SMM 本机档案的记录。执行前须先停用同一插件来源，
  可用 `smm source disable <来源ID>` 停用。

总帮助也应提示清理前须先停用对应的插件来源。

## 范围与约束

改动限于 `smm source` 的总帮助和 `purge-batch` 的子命令帮助，
用途与参数说明沿用简体中文。保留现有命令名、参数和操作行为。
