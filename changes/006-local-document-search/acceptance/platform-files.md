# TC-006-platform-files：实际文件边界证据关联

前提：三个E1正式轮已完成，安装产品字节与当前候选一致，有原始命令、普通身份、文件/响应、关键画面、trace及清理；各轮真实业务时间必须保留，不以本轮核原件时间替换。

1. 分别打开macOS、Ubuntu、Windows实际原生换行及码点原文响应，与该轮独立原始字节/规范文本预期逐值核对。
2. 检查各平台根链接拒绝与目录内链接不跟随的实际操作、状态、检索完整集合；Windows使用实际junction/非管理员worker，不能以POSIX单测替代。
3. 检查Mac/Ubuntu普通用户不可读文件的真实失败、正常文件仍可查、修复后新资格和旧ref拒绝；Windows适用的真实文件错误另核对，不假称执行了管理员ACL验收。
4. 对每个检查保留原始文件位置、SHA、实际业务版本/时间/身份和本轮核验时间，附必要PNG及完整业务JSON。引用E1原件，不重新包装为另一次平台业务运行；没有实际运行或摘要不符则不登记通过。
