# 005 使用路径与检索 Skill 核对步骤

本项是只读人工审阅：核对用户可见的文本、跳转与实际三端行为证据，不模拟安装日常 SMM，不以关键词存在代替语义判断。

## 主入口与局部输入

1. 从 README 的新功能段找到适用版本与具体指南链接。沿指南取得本机项目 ID、四种模式及空名单含义、会话 ID/归属确认标识的来源。
2. 沿同一入口找到停止/在途/Hub确认/历史副本/补传的区别，确认规则状态与传输状态分别表达。
3. 沿联合检索入口找到 CLI/MCP/Web 的默认行为、显式仅本机、共同一层范围、逐条引用读取、失败/部分覆盖解释。
4. 沿恢复入口找到实际档案/Hub状态目录的取得方式、prepare-restore清单、保留保护文件、停服/重启/查看/明确对账及过期版本处理。

通过条件：上述信息可从主入口逐步取得，局部参数含义和来源明确；正式0.4.0未提供005时直说，不能引导重复安装旧包后宣称已有新功能。保存所读文件及SHA、具体行号/原句、实际观察和未验证边界。

## Skill 与实际三端语义

1. 阅读 skills/smm-search/SKILL.md，逐项比对默认联合查询、N与本机重排、禁止外发排序正文、Hub共同一层及显式本机的区别。
2. 对比逐条reference/组合引用/旧参数读取、同号不同档案、远端不可用、当前会话排除及来源边界。
3. 对比四模式、待选择、停止与确认/在途、旧副本保留、重新允许补传、全局归属与缺cwd、恢复清单和明确对账。
4. 对照本次真实CLI/MCP/Web的实际搜索/原文/配置/断线/重启响应和独立用例，查找文字与观察冲突。原文由来源引用读取，不能用顶层Hub ID拼本机整数ID。

通过条件：Skill给Agent的默认决策、范围及读取方式与已确认SPEC和实际接口一致；凭据不回显、暂停不擅自恢复、005/旧包边界明确。只读文字审阅不算已验收安装器/自动升级，也不替代任何平台运行方式。

## Windows 长流程证据观察（如采用）

Windows完整业务由外部自动控制器在Limited交互任务或真实LocalService中执行。原生单条自动执行300秒的限制不改变产品验收范围。观察项必须明确它是对外部自动执行的人工证据核对，不能声称鼠标步骤由人工逐条完成，也不能把旧结果重新包装成新业务执行。

核对本次新任务/实际OS/非提升token、两个独立wheel全部模块SHA、过程命令与退出码、CLI/MCP/Web各自范围和引用全文、四模式/空名单/归属预览、同号ID/版本/长消息、离线/恢复/重启/补传/幂等、禁止载荷检查与任务清理。需要画面判断时打开本轮原始截图，记录所见。超时/失败只记录已到达部分；无完整本轮证据不得给出平台通过。
